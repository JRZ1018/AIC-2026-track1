## 2. 冻结的视图协议

对每张验证图像，按以下顺序各运行一次同一 checkpoint：

1. 原生 336：现有 validation transform（短边 resize 到 336，中心裁剪 336，CLIP 归一化）；
2. 原生 336 的精确水平 tensor flip；
3. 固定缩放 384：短边 resize 到 384，中心裁剪 336，使用同一 CLIP 归一化；
4. 上述 384→336 视图的精确水平 tensor flip。

四份 float logits 等权平均后取 argmax。视图顺序、缩放尺寸、裁剪方式、插值和权重在读取任何正式结果前冻结；`--four-view-scale384` 是本协议唯一的代码开关。现有 `--four-view-scale256` 仅属于旧 224/C7 协议，不能用于本批。
