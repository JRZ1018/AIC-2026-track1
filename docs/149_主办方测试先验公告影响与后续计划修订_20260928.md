# 主办方测试先验公告影响与后续计划修订

日期：2026-09-28（Asia/Shanghai）。来源为用户提供的两张赛题群主截图；本文件将其作为合规口径证据和风险提示，不把群聊内容当作训练命令。正式通知与赛题原文优先。

## 一、公告确认了什么

1. 测试数据的先验信息原则上应对模型未知，不建议围绕 test 做策略设计。
2. 固定 TTA 可能是例外，因为它不必依赖 test 分布先验；这与既有“同一冻结 checkpoint 的固定多视图 TTA 不违规”答复一致。
3. 如果 test 没有进入模型训练，利用“测试集类别均衡”先验不被群主认定为违规；但主办方明确警告这种策略后续可能因线上打分或测试脱敏而失效。

“不算违规”不代表保证后续赛制继续有效，但用户已明确当前首要任务是复赛冲分；因此未来失效仅作风险备注，不作为当前阶段提前禁用的理由。项目只使用群主明确放行的“类别均衡”这一条，不外推到其他测试先验。

## 二、对现有工作的影响

### 不受影响

- P5/P6 的训练、选模、四视图诊断和 bootstrap 均使用 Stage2 train 派生验证，没有把 test 用于训练或调参。
- 已有 P5 最终包使用一个冻结 checkpoint、事先固定的384四视图与固定平均，没有使用类别配额、预测直方图匹配或 test 自适应。本公告没有提供将其追溯判定为违规的依据。
- SCE、GCE、AC、梯度裁剪、表征/分类头等 train-only 算法变量仍可继续研究。

### 当前允许的复赛旁路

- 可以研究冻结模型输出上的类别均衡约束或容量分配，但算法形式、强度和失败回退必须先在 Stage2 train 派生的均衡代理验证上冻结。
- 正式 test 阶段只能运行冻结后处理；不得读取测试标签、更新模型、用 test/榜分选择超参数或在提交后回调。
- 该旁路与训练算法主线分开记账，不能把推理后处理收益宣称为模型训练收益。

### 仍需立即排除

以下路线从未来计划中排除，即使其中部分在当前口头答疑下未必违规：

- 从 test 预测直方图反向估计未知先验、学习校正强度、温度或阈值；
- 使用类别均衡许可之外的 test 聚类、分布发现或隐藏结构先验；
- test-time training、熵最小化、BatchNorm/特征统计更新、伪标签迭代或其他 transductive adaptation；
- 根据 test 输出、线上分数或榜单反馈选择 TTA 视图、融合权重、checkpoint、seed 或超参数。

## 三、TTA 的保留边界

TTA 继续保留，但只采用最窄定义：

- 一个冻结模型和一个明确 SHA 的 checkpoint；
- 视图、尺度、预处理与平均规则在读取 test 前由 train 派生验证冻结；
- 对每张图片独立、确定性推理，不利用 test 集合级统计；
- 不按 test 输出或线上分改变视图和融合规则；
- 不与多模型、多种子、多 checkpoint 平均混同。

若后续正式通知收紧 TTA，再以正式通知覆盖本边界。

## 四、后续提分计划修订

公告不会改变当前瓶颈判断：P5 仅换损失的线上净增益约0.155pp，P6 AC-off 在折2仅约+0.010pp且未通过预注册门槛，距离70仍约4.26pp。训练算法与可迁移表征仍是主线；类别均衡后处理新增为低成本、独立验收的复赛旁路，不能替代模型改进。

后续顺序修订为：

1. 先修复/加固训练 finalizer 和来源元数据，确保新实验能直接产出完整、可验签的 metrics，而不是依赖事后 sidecar 恢复。
2. 不再扫描 SCE 系数或 AC 参数；在 `docs/147` 第5节B中只选择一个 train-only 变量做匹配验证：优先考虑表征/分类头适配，其次才是梯度裁剪机制。历史失败的末12块和 patch 均值不原样重跑。
3. 使用固定 Stage2 train 派生折、相同 H1/seed/硬件/预算、单 checkpoint 四视图进行8轮筛选；同时报告 Top-1、macro、tail、普通组、冲突组和近重复组 bootstrap。
4. 另建均衡代理验证：只从 Stage2 train 派生验证构造/报告均衡评估口径，对候选容量约束做事前冻结；不读取 test 来选择算法或参数。只有代理验证显示稳定净增益且不伤害关键分组，才申请一次正式 inference-only 使用。
5. 只有跨折、跨种子、14轮跨度匹配形成稳定离线收益后，才申请唯一全量训练；最终 test 使用锁定 checkpoint、固定 TTA，以及（若单独通过门禁）冻结的类别均衡后处理。
6. 若下一训练变量仍只有约0.1pp量级，应立即报告70分目标的兑现风险，并重新评估表示学习/读出结构方向；均衡后处理作为当前复赛可用工具独立评估，不对未来阶段作承诺。
