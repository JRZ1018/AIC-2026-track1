# 复赛 V2 输入裁剪诊断：预注册与执行门禁

更新时间：2026-09-24（Asia/Shanghai）
状态：**首批诊断获批并完成；候选未通过门禁，已停止，不进入 test 或出包。**

## 问题与边界

Stage2 train 的宽高比中位数约 1.36，约 20.75% 的图片大于 1.5；当前验证与 test 采用短边缩放至 224 后的 224 中心裁剪，宽图可能丢失边缘信息。这只是几何风险，不等于准确率收益。前一项 CLS+patch 均值头在旧折仅提高 0.1345 个百分点且 tail 退化，已止损，不与本次改动叠加。

本次只使用复赛 **train 派生的旧固定验证折**。使用该折的 C2 `best.pt`，不使用看过全部 train 的 `final.pt`；不读取 test 图片、预测或统计。官方 OpenAI CLIP ViT-B/32、Stage2 H1、750 类映射、C2 权重、验证样本和评估口径均保持相同。北京实例不再作为执行环境，上海实例 `/data/AICtrack1` 是本轮环境。

## 唯一变量与对照

- 对照：项目当前的短边 224 缩放 + 224 中心裁剪。
- 候选：长边缩放到 224，居中填充短边到 224；填充值采用 CLIP RGB 均值，使归一化后的填充区接近零。不改模型结构、不做多视角平均、不改变 head 或训练权重。
- 两者使用相同图像 ID 与顺序、单次前向、同一 C2 固定折 checkpoint。全局 Top-1、macro、tail 样本准确率与类均召回、零召回类均报告，同时按 train 图片宽高比 `<=1.5` 与 `>1.5` 分层；对同一样本计算配对赢/输数。
- 此实验属于**现有模型的推理预处理诊断**。即使候选胜出，也不直接拿现有全量 C2 权重改 test 预处理出包；先在独立新折做从官方 CLIP 和新 H1 出发的匹配训练验证，再决定最终单模型方案。反之，负结果只否定“现有模型可零训练换预处理获益”，不能严格否定适配训练后的上限。

## 预设门禁

候选需在完整旧折的 Top-1 和 macro 同时至少高出对照 0.3 个百分点，tail 类均召回不下降超过 0.2 个百分点，零召回类不增加，并且 `>1.5` 高宽比子集有正向配对净收益，才进入新折受控训练。达不到则停止这条零训练预处理方向，不访问 test、不制造新提交包；后续重新选择独立候选。此门禁不以在线分数事后改写。

## 首批待批准资源预算

在上海 L20 上仅对旧固定验证折（约 2.97 万张复赛 train 图片）分别做两次单视角推理。预计 GPU 显存峰值低于 10 GiB，CPU DataLoader 约 8–16 线程、内存约 4–8 GiB；GPU/CPU/磁盘读取高占用预计 5–20 分钟，包含加载和核验的墙钟上限 30 分钟。新增输出仅指标、逐样本预测及日志，预计低于 0.2 GiB。此批次无训练、无 test、无提交包。中断可安全重启整批推理，结果按独立目录写入，不覆盖已有实验；若超过预算、来源哈希不符、已有训练任务或环境异常即停止并报告。

此批准若获得，**仅适用于上述首批诊断**。新折重训、全量最终训练、test 一次推理、提交包构建各需依据结果另报资源预算并分别获批。
