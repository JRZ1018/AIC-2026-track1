## SFT与全视觉后继方向

SFT是Supervised Fine-Tuning，用有标签数据监督微调预训练模型；词本身不规定解冻范围。群聊与LoRA对比时大概率指直接全参数微调。我们末8块SCE+AC已属于监督微调。TTA是推理时固定图像变换、汇总同一模型结果，不更新训练权重，两者可以同时用。

“全量数据”与“全参数”不是一回事。全量数据指148695训练图片；全参数指解冻参数范围。docs189全视觉包含全部12视觉块及视觉输入/位置/归一化/投影，H1头仍冻结，不包含文本分支或头联合训练的所有配方。相对末8块P7+0.16444444pp，CI[-0.04302605,+0.38774938]，未过原门槛；只能否定这组配方晋级。

后继优先考虑有机制依据的全视觉分层LR：浅层保留预训练能力、深层允许任务适配，固定一个可解释衰减设计，而非全局LR网格。分类头小步联合修复须先有读出失配证据，不同时叠加全解冻、头、EMA、新loss。没有文本监督任务时，不为叫全参而无目的解冻文本支路。原论文说明CLIP微调配方重要，不保证本赛收益：[CLIP Itself is a Strong Fine-tuner](https://arxiv.org/abs/2212.06138)。

## 分阶段后继实验计划

1. **当前包优先：**先完成原三seed确认，通过后全量重训/出包，不承诺超过68.3554107467151或69/71。
2. **低成本Sinkhorn核对：**仅已有train派生logits，固定kernel、边际、温度、数值稳定和停止条件，比逐行概率/预测；区分完整强度与P7的0.75。拟CPU45分钟/增量0.5GiB，启动前独立receipt。等价就停止，不新增GPU实验。
3. **单机制训练：**优先docs179弱视图AC可信度来源（保持strong训练损失），记录校正覆盖、尾类和困难类；若诊断更支持容量适配问题，则优先全视觉分层LR。两项独立串行批，不改活动源码。拟两臂20轮GPU硬6小时、留45分钟诊断、新增6GiB/free7GiB，实际新硬件吞吐估算后冻结，不追认延长。8轮只能有限观察资源/明显伤害，不改20轮终点或择best。
4. **中期拓展：**许可明确后推进同模型一致性/自蒸馏、train派生类别关系、Co-teaching。双网络先真实显存/吞吐预检，不能按单模型4GiB估内存；训练在一受控队列内，预先选最终分支。BDE辨认后插入优先级。头修复、晚期EMA、类别条件损失仅在对应机制证据明确时做，不原样重复P17/P19/P20/P18失败。

算力充裕允许研究更多不同机制，但不等于全做参数网格。可以提前实现独立未执行候选及CPU测试，不占活动GPU、不改冻结源；每个实验仍需可解释问题与有限预算。
