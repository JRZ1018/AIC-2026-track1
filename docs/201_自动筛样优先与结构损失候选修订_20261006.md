## 3. 现有AC的真实局限，而不是“完全没处理噪声”

源码`ClasswiseHistoryWeighting.update_epoch`使用逐样本detached CE、观察标签概率、历史标签一致性与预测稳定性；当前strong观察，momentum=.8/history_mix=.5/min_weight=.02/magnitude_mix=.75，warmup1。它只改变SCE监督权重：**不修标签、不删除图片、不进行硬筛样**。先前聊天“AC标签校正”措辞不准确，以本次源码核对为准。

已完本批control20 metrics SHA`300d04cf40ee911f36dd5d848eb532e4a2d369ec46c478bf7664e9da75e7d99a`：20次更新完整覆盖118958训练图/750类，均为L1。末轮weight_min≈.02/p10≈.131954/median≈.514514/p90≈.877245；class_mean_min≈.233183，未启用显式tail保护参数。

每轮平均权重约.51 **主要是分位排名到[.02,1]线性映射的结构结果**，不是测得“49%噪声”，也不等于只训练51%图片；训练损失按batch权重总量归一化。现有L1只证明工程有效质量守卫未触发L2，不证明噪声已清干净。按全局loss排序可能把尾类/困难干净图误认为噪声；hard筛样必须额外保护覆盖和恢复资格。

历史M1/M2的Stage1初赛结论不能直接当Stage2筛样失败，但不能复制旧视觉原型软权重宣称新机制。N1弱AC、N2暖头、N4层LR衰减、P19 BalancedSoftmax与P12 ELR等现有止损不重复。

## 4. 第一候选：单模型持续低可信监督门控（PF1）

已完成原创最小模块`src/aictrack1/methods/persistent_filter.py`与12项CPU测试；**未接入正式trainer，未启动新GPU批次，无效果结论**。参考上游登记M1/M3小损失课程思想，不复制Co-teaching代码、不引入双网络或独立检测器。Co-teaching论文只解释课程思想：https://arxiv.org/abs/1804.06872 。

固定首配方，不根据榜分/筛选结果扫阈值：

- 仅接受明确的训练样本ID，完整一轮原AC更新后为**下一轮**决定资格；无validation/test输入。
- AC权重≤.10、历史标签一致性≤.20、预测稳定性≥.80，三次连续更新同时满足才进入疑似名单；最早第4轮开始门控。不是仅凭高loss或低confidence删除难图。
- 每个观测标签类最多剔除floor(10%×支持数)，至少保留min(16,原类支持数)，并保留该类至少90%的原AC权重质量；小类不硬删。
- 标签不改，原图片不删。资格可以重新进入：任一条件不再满足就重置连续计数，仍按完整训练样本每轮观察，避免“被删后再也不能翻身”。
- 疑似图监督SCE贡献为0，仍只用当前同一模型的detached预测更新AC；此首实现**不减少全量图像前向，不能承诺节省30%时间**。
- 全mask batch：返回有限零损失、明确无监督标志；必须跳过optimizer/AdamW更新，仍观察预测，不能因空batch意外施加weight decay。记录实际optimizer次数、AMP skip与覆盖。
- gate的sample IDs/labels/连续计数/mask/epoch均入完整checkpoint，CPU weights_only恢复、未知ID拒绝、每类覆盖与mask边界测试必须PASS。

阈值是保守机制假设，不是最优值或真实清洁概率。先只读审计completed fold checkpoint与训练轨迹，给出“当前信号可覆盖的疑似上界”、每类变化；最终状态无法恢复每图三次历史时，不伪造persistent筛样率。若没有资格图，记录首配方空作用并转向有机制依据的课程，而不是自动扫阈值。

## 6. 后续候选排序与止损

1. **自动筛样/监督资格：现在第一优先。**不是随机70%，不是人工清洗。
2. **阶段化/混合损失：第二优先，独立消融。**当前SCE本就是CE+RCE；先分析warmup与疑似样本监督梯度，再预注册不同阶段的监督约束，不无依据叠loss/扫系数。
3. **长尾注意力读出：合法条件候选，不再因身份未核实一概排除。**优先保留完整CLIP内部结构，在输出tokens后加轻量随机初始化读出/残差模块，仅Stage2 train训练；核对参数覆盖、官方权重保留和单模型。截图没给具体算法，不能凭“涨3分”去盲选注意力。替换原骨干注意力/层数宽度是否仍CLIP另需具体核对，不自动许可。
4. **70%快筛：可选工程节省。**仅固定train侧类别/重复组受控子集，两臂共享；既定validation不被抽进筛样训练，不把70%代表清洁率。该次结果只探索，不直接出包或与全训练配方混比。
5. **已验证机制组合：必须增量消融。**最终一个模型一个checkpoint；无权重融合、投票、线上择seed。
