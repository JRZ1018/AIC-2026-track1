# H1→LoRA 轻度标签平滑预注册

日期：2026-09-12

## 实验问题

当前最佳 H1→LoRA 在固定验证集上从 epoch 1 到 epoch 3 的平均置信度持续上升，ECE 从 1.7537% 上升至 2.4307%，NLL 从 1.3664 上升至 1.3702，而 Top-1 在 epoch 2 达峰后回落。这只能支持“后段训练存在轻度过置信”的候选解释，不能证明它是榜分上限的唯一原因。

本实验检验一个低风险单变量：保持 H1 初始化、OpenAI CLIP ViT-B/32、最后视觉注意力 LoRA、固定划分、随机种子、增强、学习率和三轮训练全部不变，仅把交叉熵的 `label_smoothing` 从 0 改为 0.05。该机制不删除样本、不修改标签、不使用外部数据或测试统计，并保持单模型单次推理。

## 冻结配置与门禁

- 基线：`20260911-a-h1init-lora-only-3ep-seed1-v2`；最佳 Top-1 68.9615%、macro 68.9492%、ECE 2.2925%。
- 候选：`20260912-a-h1init-lora-label-smoothing-005-3ep-seed1`。
- 配置：`configs/experiment/p3_stage1_h1init_peft_lora_label_smoothing_3ep_seed1.yaml`。
- 标签平滑系数：0.05，在训练前一次性锁定，不围绕固定验证集搜索。
- 当前状态：用户已批准由 A 本机代执行；等价 ACL 重试已完成，结果未通过门禁。

单种子晋级要求：最佳 Top-1 至少达到 69.0615%（基线 +0.10 点），macro 不低于 68.9492%，且最佳 checkpoint 的 ECE 不高于基线 epoch 2 的 2.2925%；跨标签冲突子集不得出现异常退化。若 Top-1 未过门槛，即使校准改善也停止，因为官方主指标是 Top-1。

通过单种子门禁后才准备 seed2/seed3；三种子稳定通过后才讨论全量复训与一次新的测试推理。本实验不得与动态置信度权重或视觉原型权重叠加。

## 资源预算

单次三轮筛选预计 15–18 分钟，RTX 4060 Laptop GPU 峰值显存约 0.55 GiB，磁盘新增约 2–5 MiB。每轮保存 `last.pt`，训练可中断并从 checkpoint 恢复。启动训练前仍需用户对本次资源预算明确批准。

## 与成熟方案的关系

标签平滑属于项目既定低风险鲁棒损失对照，不依赖新的第三方代码。它承接 M2 无增益后的证据：不继续事后搜索视觉权重阈值，而转向直接抑制过置信的最小损失改动。成熟方案在本项目中的价值仍以统一固定划分上的正式消融为准，不因论文或仓库结果直接进入最终模型。

## 执行结果

A 本机等价重试于 2026-09-12 完成。最佳 epoch 3 的 Top-1 为 68.8403%、macro 为 68.8275%、ECE 为 6.1777%，分别相对基线 -0.1212 点、-0.1217 点、+3.8852 点。Top-1、macro 和 ECE 三项均未通过门禁，因此停止该参数设定，不执行多种子、全量复训或测试推理。完整验收见 `docs/27_H1_LoRA轻度标签平滑验收.md`。
