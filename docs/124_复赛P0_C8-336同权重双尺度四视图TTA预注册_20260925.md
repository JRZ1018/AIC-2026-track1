## 4. 冻结的对照与候选协议

### 4.1 对照（已记录，本批**不**重跑）

native336 中心视图 + 精确水平翻转，两份 float32 logits 等权平均。记录见 §5 表。

### 4.2 候选 C8（同 checkpoint 四次确定性前向，顺序固定）

| 视图 | 定义 |
|---|---|
| V1 native336 | EXIF 安全转置 → `convert("RGB")` → 短边 **BICUBIC 缩放到 336** → 中心裁 **336** → CLIP mean/std 归一化 |
| V2 | V1 张量 `torch.flip(dims=(-1,))` |
| V3 scale384 | 同一张图 → 短边 **BICUBIC 缩放到 384** → 中心裁 **336** → 同归一化 |
| V4 | V3 张量 `torch.flip(dims=(-1,))` |

聚合：`(L1 + L2 + L3 + L4) / 4`，float32，随后 argmax。**无 softmax、无温度、无学习权重、无视图加权。**

### 4.3 scale384 的选择依据（不看结果即可成立）

- 与 C7 已验证的 224→256 完全同族：缩放比恒为 **8/7 ≈ 1.142857**，`384 = 336 × 8/7` 恰为整数，短边缩放的取整行为与 C7 同类。
- **不做尺度搜索、不做多候选挑选**：本批只此一个 C8 候选。若失败，下一步是 `docs/121` P1（匹配 320 重训），而不是在同一 checkpoint 上换尺度重试。
- 结构说明：336 输入下未改动的 32 像素 patch 卷积实际产出 10×10 token，右/下各 16 像素不进入 patch 卷积（`docs/114`、`docs/121` 已记录）。C8 **不修改**该行为，也不改骨干拓扑、位置编码或官方权重；`clip_resolution.py` 仍只允许 336。

### 4.4 「只多了两个视图」的可验证保证

新增的成对数据集在取图上与既有单视图 `IndexedImageDataset` **完全一致**：同样的 `LOAD_TRUNCATED_IMAGES` 策略、同样**先 `convert("RGB")` 再交给变换**。因此同一张图在对照路径与 C8 路径共用同一像素来源，唯一差别就是多出的 V3/V4。

并且队列强制执行**控制分支复现断言**：本次运行重新推导的 `center` 与 `flip_tta` 两个对照 Top-1，必须分别在 **2e-4** 内复现已记录值（与诊断脚本自身的 `metrics.json.best_top1` 一致性检查同容差），否则该折**拒绝评分**。这使"只多了两个视图"成为机器可验证的事实，而不是声明。

## 7. 停止条件（任一触发即止损：不出包、保留完整产物、转 `docs/121` P1）

- 任一折 **G5 复现失败** → 立即停止排查，不得改阈值迁就。
- 任一折 `ΔTop-1 < 0`，或超过 1 折未通过单折门槛 → 停止。
- 任一折 `Δmacro < −0.25 pp` 或 `Δtail < −0.50 pp` → 停止。
- 原子训练锁已存在、或全系统进程探测失败 → 停机（fail-closed，绝不自动清锁）。
- D: 可用空间 < 20 GiB → 不启动。
- CUDA OOM（按 §8 的 batch 降级仍失败）、manifest/类映射/split SHA 不符、图像解码异常 → 停止并保留产物。
- GPU 高占用明显超出本批预算（> 45 min）或无法在安全时限内完成 → 停止，保留完整产物，重新申请。
- 任何需要读取 test 才能继续的判断 → 停止并回报（本批不读 test）。
