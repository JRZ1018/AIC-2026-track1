# P10：硬类别容量分配推理旁路预注册

日期：2026-09-29（Asia/Shanghai）。本计划仅研究赛事答疑明确提及的“测试类别均衡”类别容量先验；这是冻结单模型后的 inference-only 后处理，不改变模型参数。不得使用 test 标签、在线成绩、test 预测直方图来选择算法/参数或开展自适应。正式规则与赛事公告优先；该先验存在未来失效风险，按用户当前复赛目标保留为受限候选。

## 假设和唯一变量

P7 已冻结的参考流程为 P5 单一 SCE PEFT checkpoint、固定四视图，以及由 train 派生均衡代理冻结的统一软偏置 `temperature_multiplier=0.5, bias_strength=0.75`。本筛选不重搜该偏置，也不更改视图、checkpoint、训练或样本选择。唯一变量是：在完全相同的冻结 P7 调整后 logits 上，是否把独立样本 argmax 替换为硬类别容量约束解码。

唯一候选算法：先按 P7 冻结参数计算调整 logits 和逐样本 argmax；以 `samples_per_class=50` 构造的均衡代理为每类设容量50。对当前预测类别超额的行，枚举其转到不足类别的 logit 损失（当前类调整logit减目标类调整logit），按损失升序、再按行号及类别号稳定打破平局；仅在源类仍超额、目标类仍不足且该行尚未移动时接受移动，直到每类恰为50。完整扫描无解或容量不精确即视为实现失败。此确定性贪心规则不保证全局最优；不得增加迭代、候选排序法或参数网格来追救本筛选。

正式 test 样本数为37,444，对应平衡容量冻结为每类至少49、至多50，合计37,444；算法按同一确定性低损失移动规则满足上下界，余出的694个名额由调整logit损失最小的可行移动自然决定，不依据类别编号人为分配。开发、实现验收和一切晋级决定只可使用 Stage2 train 派生验证；test 阶段只能运行冻结实现一次。

## 固定输入与筛选流程

- 两份既有 train-derived fused logits：P7 fold2、fold3 的29,737×750 `fused_logits.pt`；来源 checkpoint SHA、split、manifest、class mapping 和 logits SHA 必须记录并验签。必须 `weights_only=True` 安全加载，逐份与同序 `paired_predictions.csv` 核对目标标签；不读取 test manifest、test 图片或已有 test 预测统计。
- 在每折验证集按类有放回抽50条，固定 seeds `20260928, 20260929, 20260930`，与P7先前代理抽样口径一致。对照是同一代理上的冻结 P7 软偏置；候选是相同调整 logits 上的硬容量解码。
- 使用 fold 对应的官方 train class counts 和既有 head/mid/tail 定义；每个 fold、每个 seed 报 Top-1、macro、tail 类均召回、普通样本组、跨标签精确冲突组、胜负和近重复组 paired bootstrap 95% CI（500 replicates，seed20260925）。普通组为不属于跨标签精确重复冲突的验证样本；近重复分组严格来自 Stage2 train 审计表。
- 仅输出独立 `artifacts/diagnostics/20260929-p10-hard-capacity-proxies/` 与 `artifacts/reports/20260929-p10-hard-capacity-screen.json`；输出不存在才可开始，数据不覆盖旧 P7 产物。保存6组代理逐样本预测、输入/源码 SHA 和完整报告。

## 预先冻结的继续/止损门槛

所有三种子先汇总到每折均值，再汇总两折；折间样本可能重叠，不称独立盲测。

- 两折合并 Top-1 增益至少 `+0.30pp`，且每折均值至少 `+0.10pp`。
- 两折合并 macro 增益 `>0pp`；tail 类均召回增益不低于 `−0.25pp`；普通样本组增益不得为负。
- 完成全部6个代理，容量精确、输入与来源 SHA 验签通过；报告近重复组 bootstrap 95% CI。CI跨0不单独否决这项旁路筛选，但不称统计显著。

未满足任一门槛则止损 P10，不扫容量、软偏置、种子或贪心算法变体；保留当前 P7 包作为现有最佳。通过只允许在 P5 同一全量单 checkpoint 上实现冻结容量逻辑、跑回归及检查器，然后对 test 做一次新目录推理和包验收；任何实现偏差、容量不精确、测试失败均取消该包，不回退后重读 test。最终不自行线上提交。

## 资源、锁和恢复

唯一机器为本机 RTX 4060 Laptop（8,188 MiB）；开始前重新核验训练锁、真实 trainer/诊断进程、GPU/显存、内存和磁盘。此阶段复用已保存的 train logits，不解码图片、不训练模型、不读 test。估计 GPU 累计占用不超过15分钟，CPU排序/分组统计不超过45分钟，峰值额外RAM不超过4GiB，磁盘新增不超过200MiB；超过60分钟、GPU显存余量低于1GiB、磁盘低于3GiB或锁/来源异常则安全退出并报告。通过仓库共享训练锁运行，锁随进程释放；报告和预测逐文件 SHA。不可续训的纯推理筛选中断后只可从头用相同输入/seed重跑，输出目录必须保持全新。
