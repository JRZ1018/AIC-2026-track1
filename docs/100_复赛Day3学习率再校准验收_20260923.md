## 3. 结论与决策

1. `lr=1.25e-6` 明显退化，淘汰。
2. `lr=2.25e-6` 接近基线但没有可复现的总体提升（Top-1 仍低 `0.0235 pp`），不晋级为正式方案。
3. 学习率轴短筛到此停止；保留 R3 已验证的 `1.75e-6` 作为当前正式 anchor，不追加多种子确认或全量训练来追逐随机差异。
4. Day3 结果仅用于验证和记录，不进入最终提交模型。下一步直接使用已锁定的 R3 anchor checkpoint 做一次 test 推理与出包；若需要新的提分实验，应另立单变量轴并先完成短筛门槛。
