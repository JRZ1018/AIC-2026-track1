## 两个独立问题

1. `last3-r4`：在末两层 rank-4 已获得三种子一致增益后，只把可训练注意力块从 2 扩展到 3；预计 55,296 个视觉 LoRA 参数。
2. `last2-r8a16`：保持末两层不变，把 rank 从 4 提升到 8，并同步把 alpha 从 8 提升到 16，以保持 `alpha/rank=2` 的缩放不变；预计 73,728 个视觉 LoRA 参数。

每组均准备 seed `20260910/20260911/20260912`，固定同一 H1 初始化、训练/验证划分、3 epochs、学习率、batch size 和增强。两组互不叠加，不构成组合模型，测试集不进入任何配置。

## 预冻结队列与资源上限

- 每组先执行 seed1。
- 只有 seed1 相对同 seed 末两层 rank-4 基线提升达到预注册门槛，且 macro、冲突子集和数值稳定性未触发停止条件，才允许继续该组 seed2/seed3。
- 若 seed1 未过门槛，跳过该组后续种子，转入下一组；不得搜索层数、rank、alpha 或学习率。
- 最多六次训练，严格串行。按 B 既有实测每次约 25–32 分钟，训练高占用预计 50–192 分钟；加环境验收、哈希、打包和可能续跑，总窗口上限四小时。到四小时边界不启动新任务，正在运行的任务允许完成当前 epoch 并保留可恢复 checkpoint。

队列优先级冻结为：先末三层 rank-4，再末两层 rank-8/alpha-16。Seed1 继续多种子的主门槛为相对同 seed 的末两层 rank-4 提高至少 0.10 点；若增益处于 +0.05 至 +0.10 点之间且 macro、冲突子集均无超过 0.05 点的退化，则只追加 seed2，再按任务单中的固定双种子门槛决定是否运行 seed3。B 不接收 `pred_results`，不运行测试推理，也不根据线上分数自行决定任务。
