## 3. 分支规则（写死）

设 `T_I` 为 I 的 seed1 最佳 Top-1，`T_J` 为 J 的 seed1 最佳 Top-1。

### 分支 1：I 通过 seed1 门槛（`T_I > 0.713759303` 且 macro ≥ `0.713626802` 且冲突 ≥ `0.310139179`）

1. 追加 seed2/seed3（**同一 commit**，修正批次 4 的跨 commit 偏差）；

3. 通过 → 全量训练 I 配置 → 唯一一次 test 推理 → **正式包**；
4. 未通过 → 转分支 2 的对照包流程（用 I 配置出对照包，理由见下）。

### 分支 2：I 未通过 seed1 门槛

1. 若 J 通过 seed1 门槛（`T_J > 0.713759303`）→ 走 J 的三种子确认 → 通过则出 J 的**正式包**；
2. 若 I、J **均未通过** → 取二者中 Top-1 较高者做**全量训练一次的对照包**，如实标注
   "未通过 seed1 门槛，不冒充最佳，仅用于线上单变量归因"；
3. 不出第三个包；本批结束。

### 特别说明：为何对照包仍值得出

对照包的线上分数与旧包分数构成**同协议下的单变量对照**（时长或权重下限之差），
其信息价值不依赖它是否通过门禁：
- 若对照包分数 ≥ 旧包 → 该变量在线上有效，即使门禁未过也值得复看门禁口径；
- 若对照包分数 < 旧包 → 该变量在线上无效，方向被排除。

## 4. 三分支处置表（预注册，分数到手后不修改）

设 `Δ = 新包线上分数 − 旧包线上分数`（旧包 = 8ep/mw0.2）。

| 观测 | 解释 | 下一步动作 |
| --- | --- | --- |
| **Δ ≳ +0.3** | 被改动的变量在线上有效，固定验证的正增益已转化 | 沿同一轴继续推进（若变量是时长 → 测 12/15ep；若变量是权重下限 → 沿下限继续扫） |
| **\|Δ\| ≤ 0.3** | 线上对该变量不敏感，固定验证增益未转化 | 停止在该轴上继续投入；转向另一轴或层间学习率 |
| **Δ ≲ −0.3** | 该变量在线上有害（例如延长训练加重噪声记忆） | 回退到 8ep/mw0.2，转向正则化/表征锚定方向 |

**该表在分数到手后不得修改**，以保持归因有效。
