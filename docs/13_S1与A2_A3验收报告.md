## 1. 结论

- S1 本地提交工程闭环已完成：CSV、ZIP、manifest、严格校验和命令行入口均已实现，未读取或推理测试图片。

## 3. LogitClip 公式纠偏

PMLR 论文公式规定 `tau` 本身是裁剪后 logits 的范数上界：

```text
clip(z) = min(1, tau / ||z||_p) * z
```

旧 P2 独立实现错误地把上界写成 `1/tau`。P2 合成冒烟恰好使用 `tau=1.0`，因此历史数值未改变；正式 A3 前已修正实现、边界测试、梯度测试和文档。未复制无许可证上游仓库源码。

## 6. 机制诊断

- A2 仅预测 172 类且 329 类零召回。500 类问题上，q=0.7 的 GCE 对低目标概率样本梯度过弱，产生严重欠拟合。
- A3 tau=1.5 对 100% 验证样本触发裁剪；A3b 即使按类别维度缩放，仍对 99.8836% 样本触发裁剪。
- A3b 相对 A3 提升 2.94 个百分点，证明阈值尺度确有影响，但仍比 A1 低 6.73 个百分点，继续搜索阈值的投入产出比不足。
- A1 验证 ECE 为 3.7069%，均值置信度 71.6164%；校准已纳入 P4 诊断。A2/A3 的校准与准确率均明显更差。
- 三个鲁棒损失实验都没有改善跨标签冲突子集，因此没有理由进入多种子确认或 ELR 对照。
