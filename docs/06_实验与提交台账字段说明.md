# 实验与提交台账字段说明

更新时间：2026-09-20（Asia/Shanghai）

## 1. 实验索引

文件：`experiments/index.csv`

关键字段：

- `run_id`：全局唯一，建议 `YYYYMMDD-HHMM_method_seed`。
- `stage`：`synthetic/preliminary/rematch/semifinal` 等明确阶段。
- `method`：主方法名称；`upstream_candidates` 填本轮实际检查或借鉴的登记 ID，多个值用 `;`。
- `data_hash/split_hash/config_hash/environment_hash/git_commit`：构成复现身份。
- `status`：`planned/running/completed/failed/aborted`。
- `top1`：官方主指标；其他 accuracy 只作诊断。
- `peak_vram_mib/duration_seconds`：资源预算依据。
- `best_checkpoint_sha256/last_checkpoint_sha256`：权重可追溯；文件本身不进入 Git。
- `decision`：`continue/stop/repeat/promote/rollback`。
- `result_dir`：对应轻量实验目录。

### 1.1 环境身份与唯一更新入口

`environment_hash` 是对 `aictrack1.environment.v1` 规范 JSON（键排序、紧凑 UTF-8 编码）计算的
SHA-256。环境对象覆盖 Python 实现/版本、系统/发行版/版本/架构、PyTorch、CUDA、cuDNN、
设备/GPU、`requirements-lock.txt` SHA-256，以及 OpenAI CLIP ViT-B/32 权重 SHA-256。

历史运行若没有保存上述完整证据，必须写 `unknown_legacy`，并在 `notes` 说明原因；不得用当前
机器状态反推或伪造旧环境。后续 `train_frozen_head.py` 和 `train_peft.py` 会在 `metrics.json`
写入完整环境对象与已校验哈希。

中央索引的唯一构建/校验入口：

```powershell
# 只读检查
.\.venv\Scripts\python.exe scripts\rebuild_experiment_index.py

# 重算 checkpoint 哈希，全部通过后才原子写入
.\.venv\Scripts\python.exe scripts\rebuild_experiment_index.py `
  --verify-checkpoints --write
```

脚本只扫描 `artifacts/experiments/*/metrics.json`；`artifacts/returns` 的回传副本不会重复入账。
已有行的人工作出决定和备注会保留，机器生成的环境、配置、数据、split、Git 与 checkpoint
身份则从原始运行产物刷新。新发现的运行若没有完整环境身份会直接失败；
`--allow-legacy-discovery` 只允许用于明确的一次性历史迁移，不得用于新训练。

示例（仅展示，不写入正式台账）：

```csv
20260910-0900_logitclip_42,synthetic,logitclip_ce,logitclip,42,<data>,<split>,<config>,<env>,<commit>,completed,0.812,0.801,0.840,0.808,0.755,1820,920,<best>,<last>,experiments/20260910-0900_logitclip_42,2026-09-10T09:00:00+08:00,2026-09-10T09:15:20+08:00,repeat,synthetic fixture only
```

## 2. 提交台账

文件：`submissions/ledger.csv`

关键字段：

- `submission_id`：全局唯一提交编号。
- `purpose/only_change`：预注册本次提交回答的问题及唯一变化。
- `run_id`：必须指向实验索引中的完成运行。
- `checkpoint_sha256/config_hash/data_hash/git_commit`：提交复现身份。
- `inference_command/manifest_path`：实际生成命令和 manifest。
- `local_top1/online_score`：本地与线上严格分离。
- `rollback_submission_id`：出现故障时的已验证回退版本。
- `status`：`prepared/validated/uploaded/scored/rejected`。
- `decision`：`keep/reject/repeat/finalist/rollback`。

提交 CSV/ZIP 被 `.gitignore` 排除，台账和轻量 manifest 可以进入 Git。禁止手工修改预测文件后不更新哈希。
