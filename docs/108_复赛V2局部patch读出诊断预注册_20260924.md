# V2：同一 C2 视觉骨干的局部 patch 均值读出

日期：2026-09-24（Asia/Shanghai）  
状态：本机 4060 的已批准批次完成；旧固定折配对门禁未通过，V2 停止，不进入全量训练或提交。

## 问题、合规与最小机制

V1 联合训练分类头仅比冻结 C2 高 0.0101 pp，tail 略退；重训近似线性头不能解释线上 57.18 与冲榜目标的差距。当前 ViT-B/32 224 输入有 7×7 个 patch，但分类只读 CLS。试验问题是：**同一视觉模型的最终局部 patch token 是否含有 CLS 未充分利用的细粒度信息？**

只从旧固定折 C2 `best.pt` 的同一次 OpenAI CLIP ViT-B/32 前向读取 transformer 输出；保留标准 CLS 路径，对另外 49 个 token 使用该模型现有 `ln_post` 和投影矩阵、求均值。两个 512 维向量各自 L2 归一化后拼成 1024 维特征，在固定 train 分区从零训练**一个线性头**。没有第二个骨干、外部权重、多个推理视角、投票或 test 数据。这个简单均值读出是本项目独立实现的最小诊断，**不是**对 [TransFG 论文](https://arxiv.org/abs/2103.07976)的 Part Selection Module 或对比损失的复现，也未复制其代码。赛题 PDF 只限制骨干为 OpenAI CLIP ViT-B/32 和最终单模型单推理流程；224 输入、官方权重和预处理保持不变。
