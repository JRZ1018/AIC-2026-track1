## 1. 结论与证据等级

**已观察到**：P5 固定 SCE 相对匹配 GCE 的三折 train 派生四视图增益均很小；线上包比此前最佳仅高 0.15489798098493 个百分点。当前这条“仅换损失”的路线不足以为冲 70 提供强证据。A10 单任务仍有吞吐优化空间，但资源利用率本身不是准确率瓶颈的证明。训练集含噪、长尾，官方 test 人工精标；折内验证到线上存在代理差异，不能用线上一次结果识别具体原因。历史公开说明曾描述 test 类别均衡，2026-09-28群主明确答复该先验在不进入训练时不算违规；当前复赛可作为独立 inference-only 候选研究，但不得进入训练/选模或借线上分调参。

**待检验假设**：SCE 与现有 AC 重加权、固定梯度裁剪之间可能存在交互；某些低有效权重类或跨标签冲突组的收益较弱。不能把这些事后分层当作因果证据、噪声真值、未来门槛或 test 调参依据。

## 4. AC、梯度与资源：机制线索，不是结论

- 折1两组 8 轮的 AC 判定均为 L1，未触发 L2；SCE 最后轮类有效质量/原始数量的最低值约 0.2375、P10 约 0.3452。AC 均值约 0.51 是策略设定下的权重概况，不等于发现训练故障。
- 梯度诊断在 `GradScaler.unscale_(optimizer)` 后调用 `clip_grad_norm_`。折1两组每轮有限梯度裁剪占比显示约 100%；SCE 每轮裁剪前有限范数均值约 26.9–53.2，GCE 约 7.83–16.06，阈值为 1。不同损失的标量尺度在这一配置下大部分被裁剪，方向差异仍可保留；不能据此断言裁剪造成了小收益。AMP 个别原始非有限范数须结合 scaler 跳步判断，不把它直接写成训练失败。
- A10 单任务 180 秒采样 GPU 均值 45.33%、显存峰值 3,287 MiB；workers 4→8 GPU 均值 45.07% 且 CPU idle 降至 3.16%。受控双任务 aggregate GPU 均值 58.27%，说明当前可降低实验墙钟成本，但简单加 workers/有效 batch 或延长 epoch 没有已验证的准确率收益（`docs/145`）。
- 全量新 H1 100 轮、PEFT 14 轮；PEFT `metrics.json` 的 14 轮墙钟约 8,425 秒，训练 loss 下降，但 `validation_count=0`，不能仅由该曲线判定欠拟合、过拟合或最优 epoch。全量前原计划的三种子完整链路与两折 14 轮匹配确认未在本次 P5 完整执行；这削弱了对全量收益的预判，不等于已查明线上小增益的原因。

## 5. 修订后的顺序与硬门禁

1. **先提高判断质量，而不是扫 SCE 系数。**冻结 Stage2 官方 train manifest、既有 split/mapping/CLIP SHA，整理折2/3 train-only 逐样本预测及来源验签（若不存在则明确记缺失，不为补全而擅自启动大批推理）。统一报告 Top-1、macro、tail、冲突与普通组、近重复组，以及 AC 类有效质量；折1单独标记为高冲突压力折。官网 test 不参与任何诊断。
2. **只选一个新的训练变量。**根据完整诊断在两条互斥方向中预注册其一：A）固定 SCE 与模型/训练设置，检验 AC 是否压制低有效质量类；若需声称“损失×AC 交互”，必须有完整匹配的 2×2 对照；B）若 AC 证据不支持，则单变量检验表征/分类头适配或裁剪阈值，不同时改损失、头、输入和梯度。历史已失败的末12块、patch 均值不原样重跑。新方法进入实现前补来源/许可/合规检查。
3. **恢复正式晋级门禁，避免用时间代替证据。**候选/对照同 split、同折内 H1、同 seed、同硬件和四视图；先 8 轮筛选，按新批事前冻结的 Top-1、macro、tail、组 bootstrap 及 AC 质量规则判定。进入全量前必须完成 `docs/141` 要求的多种子完整链路、两折 14 轮跨度匹配和事前 gate receipt；失败则止损，不因 70 目标事后改门槛。折间重叠要报告，不称独立盲测。
4. **只在有足够离线信号时投入全量。**从官方 OpenAI CLIP 与新全量 H1 复训唯一模型；最后只用锁定单 checkpoint/固定 TTA 对 test 做正式推理。没有稳定收益时保留 65.7435 现有最佳，不为了新包或累计训练时长做无证据提交。

## 6. 2026-09-28 测试先验公告后的覆盖条款

本节只覆盖未来推理与策略选择边界，不改写上述历史实验事实。当前复赛允许单独研究“test 类别均衡”这一条明确获答复的 inference-only 先验，例如冻结的类别容量约束；算法形式和强度必须先在 train 派生均衡代理验证上冻结。仍禁止从 test 预测分布反向学习参数、熵最小化、BatchNorm/statistics 更新、伪标签循环或其他 transductive/test-time adaptation。固定 TTA 仍限于读取 test 前已由 train 派生验证锁定的单 checkpoint、确定性视图和固定平均；不能依据 test 输出或线上分选择视图。
