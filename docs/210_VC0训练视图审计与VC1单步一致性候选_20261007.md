## 3. 冻结VC1假设与对照

不根据初始化分歧直接声称能涨分。优先检验中心—原裁剪，不强制两随机裁剪相互一致：

`L = 原strong视图SCE+原AC监督损失 + JS(p_current,strong, p_current,center)`。

- 固定系数1.0、温度1.0；JS为两视图均值KL，独立两分支均保留梯度，不detach教师、不加历史状态。JS不依标签，且不再加一轮AC观察。不会扫描系数选线上分数。
- 原strong图像/样本顺序/增强随机流不变；只添加同train图确定中心分支。AC仍只观察原strong logits，每epoch一次，从0开始；不叠BC1/PF1/prefix/readout/EMA，不删图改标签。
- 同118958/29737、H1、seed20261005、336/b64/8workers/prefetch2/末8块96参数/冻结头/SCE(.1,1,-4)/LR1.75e-6/WD.01/clipnorm1/20完整余弦。
- 对照复用已验CLS20及四视图bundle，必须确认完整配方/行来源协议一致；披露历史时段复用、含噪非盲split、单seed和额外前向成本，不称同时随机化/等算力配对。
- 与P14不同，中心分支不是固定初始化参数；与N1不同，中心分支真正进入当前step梯度。以中心train信号选择假设，不接触test/线上分数反调参。
