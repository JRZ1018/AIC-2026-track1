# 关于举办第八届全球校园人工智能算法精英大赛“算法挑战赛道”竞赛的通知

- 来源：https://www.aicomp.cn/notice/notice-1/3629.html
- 发布单位：全球校园人工智能算法精英大赛组委会
- 文号：全智赛组委会〔2026〕10号
- 发布日期：2026-04-29

## 一、参赛对象

全球高校和科学研究机构拥有正式学籍的在读学生（含研究生、本科生、专科生）均可报名参赛。

## 二、赛制与赛题

本赛道采用“赛马制”，所有参赛团队不分赛区，由全国组委会统一组织，复赛等同省级赛事。

赛题包括：

1. 基于大模型的多模态视觉理解与推理
2. 面向城市场景的视觉多模态目标检测
3. 无人机低空航拍图像语义分割
4. 面向噪声标签数据的细粒度图像识别鲁棒微调
5. 基于虚拟染色的免疫组化图像生成

各赛题的具体规则另行公布。

## 三、赛程安排

1. 报名：2026年4月28日起开放，具体截止时间以报名系统为准。
2. 复赛：计划于2026年9月中旬前开始。
3. 半决赛：计划于2026年10月10日前开始，具体时间以赛道公告为准。
4. 总决赛：计划于2026年11月中下旬举行，时间和地点另行通知。
5. 具体比赛流程以附件《第八届AIC算法大赛算法挑战赛道比赛流程》为准。

## 四、参赛要求

1. 可单人组队，也可与本校（不含分校）学生组队；每队最多3名成员，最多2名指导教师；跨校组队无效。
2. 每队设置1名队长，队长负责接收赛事通知。
3. 每个团队可以报名多个赛题；同一赛题中，每位选手只能加入一个团队。
4. 参赛作品必须是在本届大赛期间创作的原创作品。抄袭、雷同、弄虚作假、版权不清晰等将导致取消资格和奖项。
5. 按每队500元标准缴纳参赛费；参赛期间的食宿、交通等费用由团队自行承担。

## 五、奖项设置

### 复赛

每道赛题分别设置一、二、三等奖，获奖作品数量原则上分别不超过该赛题有效作品数的15%、25%、30%，取整计算。若某赛题作品数少于10个，可由评委根据成绩确定获奖名单。复赛获奖证书为省级证书。

### 总决赛

每道赛题分别设置一、二、三等奖，获奖作品数量原则上分别不超过该赛题有效作品数的15%、25%、30%，取整计算。若某赛题作品数少于10个，可由评委根据成绩确定获奖名单。总决赛获奖证书为国赛证书。
