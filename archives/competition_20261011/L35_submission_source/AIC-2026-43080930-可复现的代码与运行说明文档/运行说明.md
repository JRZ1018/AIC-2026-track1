# AIC-2026-43080930 运行说明

本说明给出复现本作品所需的全部命令：文件验签、冻结预测复现、从官方图片生成正式预测、最终全量训练，以及训练派生验证。路径均从作品根 `AIC-2026-43080930-两股王霸之气-复赛-张延瑞/` 起算，命令也在作品根执行。

## 一、文件与运行位置

| 内容 | 位置 |

| 代码入口 | `AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/` |

按 `AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/环境与来源说明.md` 建立环境。原正式训练环境为 Linux、Python 3.12.3、Torch 2.11.0+cu128。入口会自动把 `vendor/` 与 `src/` 加入导入路径。

取得授权的官方图片后放到作品根 `DataSetStage2/`；运行中产生的新输出、虚拟环境与重训 checkpoint 统一写入作品根 `runtime_outputs/`。

## 二、无需官方图片的验签与缓存复现

```bash
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/verify_release.py'
```

该入口逐条核对 `RELEASE_SHA256.json` 清单中的文件 SHA，并检查 `提交结果/` 中的预测格式：37,444 个唯一官方 JPG 文件名、四位官方类别映射、无表头两列 CSV、ZIP 根层单 CSV 及 CRC。

### 2.2 CPU 单模型合成输入前向

```bash
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/infer.py' --synthetic-smoke --device cpu --workers 0 --output './runtime_outputs/cpu_smoke'
```

此模式构造合成 336×336 输入，检查模型加载、分类头、四视图前向与同次 512 维特征出口，不读取官方测试图片。

### 2.3 精确复现冻结后处理

```bash
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/postprocess.py' --output './runtime_outputs/cache_replay'
```

读取 `reproduction_cache/` 中的冻结测试 logits 与同次特征，执行固定 k 近邻图平滑与类别均衡后处理，并校验输出 CSV 与正式提交字节一致。此步骤不需要图片，也不执行模型前向。预期 CSV SHA：

```text
e02a214cc0ba4476501698b75a546d3d29bc5ee1942f5c91dccf6751a78a7d7f
```

输出写入 `runtime_outputs/` 下的新目录，每次执行使用新的或空的输出目录。

## 四、最终全量训练复现

### 4.1 使用随包的分类头初始化进行联合训练

须有授权的 `DataSetStage2/train/`；数据根参数指向包含该子目录的 `DataSetStage2/`。

```bash
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' full --data-root 'DataSetStage2' --work-dir './runtime_outputs/full_retrain' --device cuda --workers 8
```

默认使用 `AIC-2026-43080930-可执行模型文件或容器化复现环境/h1_full100.pt` 作为分类头初始化，视觉部分从官方 CLIP 权重初始化。固定全部 148,695 张训练图、0 张验证图、seed `20261010`、SCE `0.1/1.0/−4`、置信度加权、视觉/分类头学习率 `3.5e-6/5e-6`、AdamW/余弦 20 轮、batch 64，固定末轮导出。完整配置由脚本生成并保存到指定工作目录。

### 4.2 从官方权重与全部训练图片重建分类头

如需从零重建完整初始化过程，先提取官方冻结特征，再固定 100 轮训练分类头：

```bash
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' features --data-root 'DataSetStage2' --work-dir './runtime_outputs/features' --split full --device cuda --workers 8
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' h1 --cache './runtime_outputs/features/cache' --work-dir './runtime_outputs/h1' --scope full --device cuda
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' full --data-root 'DataSetStage2' --work-dir './runtime_outputs/full_from_scratch' --head-checkpoint './runtime_outputs/h1/last.pt' --device cuda --workers 8
```

特征提取固定使用官方 CLIP 336 中心裁剪、L2 归一化和 float16 缓存；分类头训练使用 Adam、学习率 0.01、batch 4096、seed `20261008`，不启用 AMP，取固定第 100 轮状态。`--scope full` 合并历史 train/validation 分区为全部 148,695 行训练数据；`--scope heldout` 仅使用对应 train 分区。

## 五、训练派生验证复现

最终全量 checkpoint 使用了全部官方训练图，不能用于训练派生持出集验证，验证入口会拒绝这种用法。验证需重新训练对应划分的初始化头与候选模型：

```bash
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' features --data-root 'DataSetStage2' --work-dir './runtime_outputs/first_features' --split first --device cuda --workers 8
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' h1 --cache './runtime_outputs/first_features/cache' --work-dir './runtime_outputs/first_h1' --scope heldout --device cuda
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/train.py' heldout --data-root 'DataSetStage2' --work-dir './runtime_outputs/first_train' --split first --head-checkpoint './runtime_outputs/first_h1/last.pt' --device cuda --workers 8
python 'AIC-2026-43080930-完整的训练、验证、推理脚本及环境配置说明/scripts/validate.py' --checkpoint './runtime_outputs/first_train/checkpoints/final.pt' --data-root 'DataSetStage2' --split first --output './runtime_outputs/first_validation' --device cuda --workers 4
```

第二固定划分使用 `--split second` 和独立工作目录。初始化头只由对应的 118,958 张训练样本拟合；第一视觉 seed 为 `20261008`，第二为 `20261010`。

验证包含自然 29,737 张与均衡 738×20 张两个范围，各自执行冻结四视图、固定图平滑与均衡后处理。来源证据在 `evidence/provenance/first/` 与 `evidence/provenance/second/`；文件身份与统计范围见 `TRAINING.md`。
