## 2. 环境身份规范

环境哈希是对键排序、紧凑 UTF-8 JSON 计算的 SHA-256。规范对象至少覆盖：

1. Python 实现与版本；
2. 操作系统、发行版、系统版本与机器架构；
3. PyTorch、CUDA runtime 与 cuDNN；
4. 运行设备与 GPU 型号；
5. `requirements-lock.txt` SHA-256；
6. OpenAI 官方 CLIP ViT-B/32 权重 SHA-256。

`src/aictrack1/engine/environment_identity.py` 负责捕获、校验、规范化和哈希。缺字段、错误
SHA-256 或对象与声称哈希不一致时硬失败。

## 3. 索引唯一入口

`scripts/rebuild_experiment_index.py` 是中央索引唯一构建/校验入口：

```powershell
# 只读检查，不写文件
.\.venv\Scripts\python.exe scripts\rebuild_experiment_index.py

# 校验 checkpoint 后原子更新
.\.venv\Scripts\python.exe scripts\rebuild_experiment_index.py `
  --verify-checkpoints --write
```

规则如下：

- 保留已有行的人工 `decision` 和 `notes`；
- 从原始运行产物刷新环境、配置、数据、split、Git 与 checkpoint 身份；
- 只扫描 `artifacts/experiments` 的一级运行目录，不扫描 `artifacts/returns`；
- 新运行从 `metrics.json` 与 `config.yaml` 生成索引行；
- 不完整历史环境写 `unknown_legacy` 并附原因；
- 默认拒绝任何缺完整环境身份的新运行；`--allow-legacy-discovery` 仅供一次性历史迁移；
- 重复 run_id、目录越界、环境哈希不一致、checkpoint 缺失/不一致均停止且不写索引；
- 重复执行幂等：本次写入后只读复查为 137 → 137、added 0、refreshed 0。

## 6. 剩余边界

`unknown_legacy` 是历史证据缺失的明确标记，不影响初赛结果真实性，但不能被描述为完整可复现
环境哈希。第一个在本改动后执行的真实训练应在开跑前确认 `metrics.json` 会落下规范环境对象；
训练结束后再运行索引脚本，其 `environment_hash` 必须是 64 位 SHA-256，而不能继续为空或为
`unknown_legacy`。
