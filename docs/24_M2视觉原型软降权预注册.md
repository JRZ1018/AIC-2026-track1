# M2 视觉原型软降权预注册

日期：2026-09-12

## 背景与上游使用情况

当前全量 H1→LoRA 线上分数为 57.8924，说明 H1 初始化后的轻量视觉适配有效。此前成熟方案并非全部落地：OpenAI CLIP 底座与工程实践已采用；DivideMix/Co-teaching 启发的 M1 软权重三种子收益不足而停止；DeFT 与 CLIPCleaner 的核心视觉可信度机制此前只完成审计。

本轮开始使用后两者的最小合规思想，但不复制其完整训练栈：只用当前阶段官方训练集的冻结 OpenAI CLIP 特征建立视觉原型，以单模型训练期权重影响同一个 H1→LoRA 模型。由于类别只有数字 ID，不使用文本 Prompt、外部类描述、额外数据、独立检测模型、标签修复或测试统计。

## 离线诊断

原型仅由固定训练 partition 构建，并以留一法给训练样本打分。信号包括样本与观测类别原型的相似度，以及相对最强其他类别原型的 margin。最低目标相似度 5% 样本中的跨标签完全重复冲突比例是总体的 1.88 倍，证明该信号能捕获一部分确定冲突。

按类双分量 GMM 的大范围划分会同时覆盖大量困难样本，且分量概率对不同信号的解释不稳定，因此本轮不采用 GMM 硬筛。改为类内排名后只对最低可信 10% 做连续软降权，最低权重 0.5；全部样本与原标签均保留。

## 单变量实验

- 基线：`20260911-a-h1init-lora-only-3ep-seed1-v2`，Top-1 68.9615%、macro 68.9492%。
- 候选：`20260912-a-h1init-lora-visual-prototype-3ep-seed1`。
- 相同项：H1 初始化、OpenAI CLIP ViT-B/32、LoRA rank/alpha、seed、3 epochs、学习率、增强、batch、固定划分。
- 唯一变化：训练 CE 使用预先锁定的视觉原型静态软权重。
- 配置：`configs/experiment/p3_stage1_h1init_peft_lora_visual_prototype_3ep_seed1.yaml`，当前 `execution_enabled: false`。

单种子晋级门禁：最佳 Top-1 至少达到 69.0615%（相对基线 +0.10 点），macro 不低于 68.9492%，且跨标签冲突子集不出现异常退化。未通过即停止；通过后才安排 seed2/seed3，相同三种子门禁通过后才讨论全量复训。测试集不参与任何阶段选择。

## 资源预算与恢复

训练前静态可信度计算预计 10–20 秒、CPU 内存约 0.3 GiB；三轮 LoRA 预计 15–18 分钟，GPU 峰值约 0.55 GiB，磁盘新增约 2–5 MiB。训练每 epoch 保存 `last.pt`，可中断并从 checkpoint 恢复。必须得到用户对本次资源预算的明确批准后，才能把配置解锁并启动。
