## 更新规则

1. 新通知到达后保存原文或截图位置、发布日期和来源链接。
2. 先判断是否覆盖已有条款，再更新规则摘要、`AGENTS.md` 和工作计划。
3. 对口头或群聊答复，记录答复人、时间和原始消息位置；未经确认不采用宽松解释。
4. 不在本文件记录数据下载链接、提取码、账号或其他敏感信息。
