2026-10-07 docs219原创局部组支持：query整近重复组排除、16个不同邻居组各一票/冲突标签比例分配，仅train描述性统计，不拟合检测头/改监督权重或标签/进入推理、不解除C13/M5。10CPU边界测试及独立有限receipt先于真实缓存，机械或非冗余PASS不自动launch正式候选。

## 2026-10-07 SAM0/SAM1最小边界（实现前）

独立实现L2扰动eps=rho*g/||g||，固定rho=.05来自论文默认建议，不扫描。只接受有限浮点且requires_grad的准确参数与同形有限梯度，保存原值后copy_精确恢复（禁止减eps冒称逐位恢复）；异常finally恢复、零梯度/零rho不改变参数，拒绝嵌套和协议漂移，扰动中不得正式checkpoint。CPU边界/禁用/有限二次梯度/weights_only协议测试先于真实CUDA。SAM0仅固定750train每类1张、同增强输入的base/plus/minus邻域及梯度审计，无optimizer/AC更新/val/test；非线性曲率与梯度变化只是机制可行性，不是提分。SAM1若支持才接完整96 optimizer/scheduler/scaler/RNG/AC恢复及实际batch64预检，fresh官方CLIP/AC0，原AC只原strong每epoch一次；同输入第二反向，不叠其他失败候选。原clipnorm1用于实际更新，不扫描clipnorm；不同于P9。保持原P7/保护阈值与至少3训练seed后fresh全量门禁。

## 1. 使用原则

本文件把上游论文/仓库转换为后续可实现、可测试、可退出的任务规格。它不是第三方源码副本。实现前必须同时检查 `docs/04_上游方案调研与复用登记.md`、`docs/upstream_registry.yaml` 和 `docs/compliance_questions.md`。

所有算法模块必须满足：一份正式 checkpoint、固定可复现的单模型推理流程即可得到最终预测；测试集不参与训练统计；只使用当前阶段官方训练数据；骨干固定为 OpenAI 官方 CLIP ViT-B/32。原先“一次标准图像前向”的保守限制已由 2026-09-24 赛题群主对同一 checkpoint TTA 的明确回复放宽为固定多视图单模型推理，**不**放宽多模型/多 checkpoint 融合禁令；证据及边界见 `docs/compliance_questions.md` C07。

## 2. P3：OpenAI CLIP 官方底座

最小接口：

```text
load_clip_vit_b32(weight_path, expected_sha256, device) -> model, preprocess, metadata
```

必须验证：

- 权重 SHA-256 精确匹配登记值。
- 模型名称、输入尺寸、归一化均值/方差和中心裁剪与官方实现一致。
- 默认只从本地显式路径加载，禁止运行期隐式联网下载。
- 冻结特征、训练和推理路径使用同一模型定义。
- 记录参数量、可训练参数量、单批吞吐和峰值显存。

退出条件：无。环境不兼容时只做数值等价的兼容封装，不能改用其他权重来源。

## 3. P2/P3：LogitClip-CE 独立实现

P2 工程验收状态：`99b1b1f` 已完成形状、精度、边界、极端值、有限差分梯度、CPU/CUDA 和 AMP 测试，并在已知噪声基准中确认实际触发裁剪。P3 A3/A3b 已完成，分别为 58.237%/61.175%，均低于 A1 的 67.909%；初赛冻结头路线按门禁停止。

2026-09-10 论文公式复核纠偏：`tau` 是裁剪后 logits 的范数上界，即 `min(1, tau / ||z||_p) * z`，不是上界的倒数。旧 P2 冒烟使用 `tau=1.0`，因此数值不受两种解释差异影响；A3 必须使用修正后的直接上界语义。

依据 PMLR 论文公式独立实现，不查看或复制无许可证仓库源码到项目文件。

最小接口：

```text
logit_clip(logits, tau, p_norm) -> bounded_logits
logit_clip_cross_entropy(logits, targets, tau, p_norm) -> scalar_loss
```

测试：形状/设备/精度保持；阈值内恒等；阈值外范数受限；有限差分/反向梯度；极大 logits 不产生 NaN；CPU、CUDA AMP 一致性。

实验：A3 对比 A1 的普通 CE 和 A2 的 GCE，仅改变损失。单种子无增益则停止；有增益再三种子确认。

## 4. P2/P3：ELR 基础单模型版

P2 工程验收状态：`99b1b1f` 已完成 EMA 定义、乱序批次、状态恢复、实际张量字节数、内存门禁和 CPU 状态/CUDA AMP 测试；合成训练中断续跑与不中断结果逐元素一致。P3 冻结特征正式对照因 A2/A3 无增益而未执行。2026-09-29 仅在 Stage 2 PEFT/H1 语境下按 `docs/157_P12_ELR复赛单折配对短筛预注册_20260929.md` 有界再检验；此处不预设效果。

只研究基础 ELR，不引入 ELR+ 或额外模型。

最小接口：

```text
ELRState(num_samples, num_classes, dtype, storage_device)
elr_loss(logits, targets, sample_indices, state, beta, lambda) -> scalar_loss
```

资源门禁：按 2026-09-13 官网现行复赛规模约 `148695 × 750`，完整状态 float32 约 0.42 GiB、float16 约 0.21 GiB，且不含框架开销。不得默认驻留 8 GiB GPU。先比较 CPU float16 状态、分块更新和明确标记为近似方法的 top-k 状态；近似版本不能冒充原始 ELR。

测试：相同样本索引的 EMA 更新；乱序 DataLoader 可复现；状态随 checkpoint 保存/恢复；内存实测；AMP 下有限值。

退出条件：无法在可接受内存/传输成本下保持算法定义，或相对 GCE/LogitClip 无稳定收益。

## 5. M2/M3：DeFT 启发的可信度

在获得 C04/C13/C17 答复前，不实现独立阶段一检测模型，也不使用外部类描述。

最小接口：

```text
compute_deft_style_trust(image_features, class_targets, positive_refs, negative_refs) -> trust
```

两种合规分支：

- 有官方语义类名：使用 OpenAI CLIP 文本编码器、一个固定通用模板和可审计的正/负提示机制。
- 无语义类名：改为只由当前训练集构造的视觉类别原型/负原型；必须标为“DeFT 启发”，不能声称复现原方法。

输出只是一维样本可信度或软权重，不在最终推理中保留检测分支。先与 M1 的类内损失+历史稳定性比较，再决定是否进入 M3。

测试：类内阈值不受类别样本量直接支配；每类最低保留；无空类；全同分数和极小类行为明确；计算不读取验证/测试样本。

退出条件：需要外部语义知识、组委会否定训练辅助机制、筛样精度/尾类表现无稳定改善。

## 6. M2/M3：CLIPCleaner 启发的类内筛选

最小接口：

```text
compute_clip_scores_batched(image_features, class_references, chunk_size) -> target_score, max_score
fit_per_class_gmm(scores, targets, min_samples, seed) -> clean_probability, diagnostics
select_with_class_floor(probability, targets, threshold, min_keep) -> weights
```

约束：不构建常驻的全量 `N×K` float32 矩阵；相似度必须分块。逻辑回归若启用，只能在当阶段训练划分上拟合，并作为训练期筛样器；其单模型合规性需结合组委会答复。

测试：GMM 随机种子固定；单峰/小样本类安全回退；每类保留门槛；分块与小规模全矩阵数值一致。

退出条件：官方无语义类名且视觉分支不优于 M1；GMM 对阈值/随机种子高度敏感；资源成本过高。

## 7. M5：JoAPR 启发的标签修复

只有 M3/M4 的软权重方案通过三种子确认后才允许启动。

最小接口：

```text
partition_by_class(trust, targets, class_policy) -> trusted, uncertain
refurbish_targets(logits_history, targets, trust, temperature, cap) -> soft_targets
```

必须设置修复比例上限、类内门槛和 warm-up；禁止一次性硬改全部低可信标签。对照组必须是同一 M3/M4 方案但不修标签。

退出条件：尾类退化、阈值敏感、修复后预测塌缩、只有单次榜单收益或组委会不允许。

## 8. 工程与排除类参考

- CoOp：只检查 Prompt Learner 是否将文本特征、上下文参数和分类接口解耦；不使用其外部预训练 prompt 权重。
- Dassl：只借鉴 Dataset/DataManager/Trainer/Registry 的职责边界；本项目保持轻量实现。
- OpenCLIP：只检查 CLI、AMP、梯度累积、checkpoint 和日志清单；模型加载路径不得依赖其权重注册表。P3 已落实 CLI、AMP、可恢复 checkpoint 和哈希日志，未引入 OpenCLIP 依赖或非 OpenAI 权重，证据见 `docs/14_P3_PEFT资源与短程筛选报告.md`。
- DivideMix：只借鉴 warm-up、逐样本损失和 GMM 诊断；不得实现双网络交叉划分。
- Co-teaching：只借鉴小损失课程的对照设计；无许可证且核心为双网络，禁止复制代码和原样采用。

## 9. 强制回填

### 2026-10-08 LR1低秩视觉新配方

仅本仓原创LoRA矩阵参数化，官方CLIP末8块QKV/out_proj/c_fc/c_proj rank8alpha16，共64张量786432参数；基础矩阵/H1冻结，零B初始化，独立CPU RNG不污染原loader。精确配方、prospective探索门与有界预算见docs224，registry作者SHA/MIT已核但不复制源。禁用保留原96参数路径；启用真实64梯度/optimizer全moments安全恢复与原增强顺序预检。单模型折叠必须验证矩阵身份与同条件输出；不可把checkpoint或seed平均说成折叠。只使用Stage2当前官方训练数据/官方OpenAI权重，旧失败入口不复活。

### 2026-10-07 MX0/MX1输入混合条件候选

论文思想来源/固定作者SHA/CC-BY-NC许可及不复制策略已登记docs04。只从本阶段train批内凸组合图像和两个给定标签的SCE项，不使用预测生成修复标签；不解除M5前置门。权重必须同lambda匹配，按`sum(lambda*w_i*L_i+(1-lambda)*w_j*L_j)/sum(lambda*w_i+(1-lambda)*w_j)`归一，不将soft target直接塞入硬标签RCE公式。固定独立RNG不消费原loader随机流；lambda1禁用等价、0/1边界、class质量守恒、有限梯度、协议安全往返/拒绝漂移均须测试。先有界MX0初始模型train内几何审计，支持只解锁正式接线/预检，不代表效果PASS。

### 2026-10-07 VC0/VC1同模型视图一致性条件候选

AugMix作者来源、固定SHA和Apache-2.0许可登记见docs04/registry。只根据arXiv:1912.02781v2式2独立实现`view_jensen_shannon(logits_a, logits_b, reduction)`，无detach教师/历史/第二网络，FP32稳定log_softmax与logaddexp均值；不复制完整AugMix或替换骨干。CPU须覆盖对称、相同视图近零、非负/上界ln2、极端logits、两个分支有限梯度与错误输入。VC0固定train每类1张有界真实模型增强分歧，零优化步，不读val/test；其PASS不是提分。

正式VC1只有train信号/成本支持且禁用等价、真实CUDA两分支参数有限梯度/完整安全恢复通过才冻结独立训练source/config/对照/预算；不扫系数、不继承失败BC1首轮权重。原P7及保护门槛保持，失败不扩多seed或出包。此候选不是M5改标签，不解除M5、双网络或test许可前置门禁。

### 2026-09-27补充：P5 SCE最小接口

后续授权更新：本机4060首折配对见docs/142。两组新增同一诊断/安全RNG序列化选项，未改变损失公式或AC历史；100项CPU回归与64张train AMP冒烟通过，未有真实提分证据。3090配对仍禁用，后续批次未解锁。

`symmetric_cross_entropy(logits, targets, alpha, beta, log_zero, reduction)`：依据arXiv:1908.06112v1式(5)/(7)独立实现硬标签公式；作者仓库仅登记、不复制未确认许可代码。FP32 `alpha*(-log p_y)+beta*A*expm1(log p_y)`，不是Label Smoothing。无额外训练模型、历史矩阵或推理分支。

测试覆盖3/750类与dense RCE等价、三种reduction、解析梯度、FP16输入/FP32计算、极端错误logits、CE/RCE边界、无效系数/形状/标签、PEFT CE/GCE逐值回归及AC加权接口。CPU测试不等于GPU AMP或Stage2效果通过。

试验只变损失配方；AC历史仍detached CE。固定(.1,1,A=-4)首筛，相同LR下梯度尺度不同需报告，不声称它是本题最优。P5配置禁用，逐批预算批准后串行开训；双折正收益、完整链路三seed和14轮匹配确认见docs/141，失败不扩大搜索。
