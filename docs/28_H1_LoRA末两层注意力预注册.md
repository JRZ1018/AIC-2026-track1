# H1→LoRA 末两层注意力预注册

日期：2026-09-12

## 实验问题

当前线上最佳只在 OpenAI CLIP ViT-B/32 最后一个视觉注意力块注入 rank-4 LoRA，并稳定带来约 0.2764 点三种子平均本地增益。M1、视觉原型权重和 0.05 标签平滑均未产生额外收益，说明当前阶段更值得先验证基础适配容量，而不是继续叠加噪声权重。

本轮保持 H1 初始化、rank/alpha、固定划分、seed、增强、学习率、冻结分类头和三轮预算不变，唯一变量是把 LoRA 范围从最后 1 个视觉注意力块扩展到最后 2 个。训练参数从 18,432 增至 36,864，仍是单一模型和单次推理；推理前全部 LoRA 权重折叠回同一个视觉编码器。

## 门禁

- 基线：`20260911-a-h1init-lora-only-3ep-seed1-v2`，Top-1 68.9615%、macro 68.9492%。
- 候选：`20260912-a-h1init-lora-last2-r4-3ep-seed1`。
- 配置：`configs/experiment/p3_stage1_h1init_peft_lora_last2_r4_3ep_seed1_a.yaml`。
- 晋级：最佳 Top-1 至少 69.0615%，macro 不低于 68.9492%，冲突子集无异常退化。

未过门禁即停止，不搜索层数、rank 或学习率；通过后才建立 seed2/seed3 配对配置。多种子稳定后才能进行全量复训与测试推理。测试集不参与任何选择。

Seed1 最佳 epoch 3 的 Top-1 为 69.1215%、macro 69.1083%，分别相对一层基线提高 0.1600 点和 0.1592 点；冲突/非冲突子集分别提高 0.2650 点和 0.1517 点。完整通过单种子门禁，可进入 seed2/seed3 配对确认。两次训练合计预计 35–45 分钟、峰值显存约 0.65 GiB、磁盘新增 6–12 MiB；该扩大预算仍需用户再次明确批准。
