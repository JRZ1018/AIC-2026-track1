## 2. Stage 1 参考点而非结论

S2/S3 的共同起点为末 4 个完整视觉块、冻结头、batch 64、weight decay 0.01、clip 1.0、
visual lr `1.75e-6`、16 epochs。S3 使用 warmup 1、momentum 0.8、history mix 0.5、
min weight 0.02、magnitude mix 0.75。

这些值只来自初赛 AC，不声称适合复赛。特别是 `min_weight=0.02`：若 B09 有效质量诊断把
任一类推到 L2，S3 立即停止，不以总体 Top-1 掩盖尾类塌陷。

## 3. 晋级与停止纪律

1. 先确认 loss 有限、checkpoint 可恢复、全部类别有训练支持且环境/数据身份完整。
2. 单种子短筛只用于淘汰明显退化：总体 Top-1 不得比直接上游低超过 0.5 个百分点；macro、
   tail 和冲突子集任何一项明显塌陷都停止。
3. 进入多种子必须满足一个预注册证据：总体 Top-1 提升至少 0.05 个百分点，或 macro/tail
   提升至少 0.10 个百分点且总体不下降超过 0.05 个百分点。
4. 多种子只报告分布与稳定性，不平均模型；通过后才固定 epoch 做一次全量复训。
5. 每轮只改一个主变量；未触发 L1/L2 时不得加入长尾机制。
6. test 不参与短筛、阈值、先验、停止或选模；线上结果不反向修改已经看过 test 的包。

数据到手后可因实测资源缩短首个短筛 epoch，但必须在启动前写入任务单，不能根据中途结果
临时延长或追加网格。
