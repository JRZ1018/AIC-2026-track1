## 可直接向组委会发送的精简问题

1. 单模型限制是只约束最终提交与推理，还是也禁止训练期的独立检测器、EMA 教师或两阶段辅助模型？
2. 是否允许在 OpenAI 官方 CLIP ViT-B/32 上使用 LoRA、Adapter、Prompt Tuning、局部解冻等参数高效微调？
3. 是否允许只利用当前阶段训练集的损失、历史预测、类别视觉原型和类内 GMM 自动筛样或生成软标签？
4. 若官方提供语义类别名，是否允许用 CLIP 文本编码器和一个固定通用模板编码类别？多模板平均是否算多模型/多推理？
5. 是否允许训练期用冻结原始 CLIP 特征做表征锚定，而最终仅提交一个微调后的模型？
6. 是否允许单模型多裁剪或翻转 TTA？
7. 不同赛段是否必须从 OpenAI 官方初始权重重新训练，还是允许继承上一赛段 checkpoint 或统计量？
8. 是否允许同一配方训练多个随机种子、分别提交单一 checkpoint 并按线上最高分择优？明确禁止的种子平均、权重融合和投票边界是什么？
9. 复赛类别 ID、目录到 ID 映射、test 子目录和 CSV 首列/表头的正式契约是什么？
10. 复赛代码、模型、环境、结果文档与作品文档的文件格式、大小、链接数量、有效期和访问权限要求是什么？
11. 原生 OpenAI CLIP ViT-B/32 若只改变输入分辨率并插值视觉位置编码，是否仍满足本题固定骨干要求？
12. 官网关于复赛是否计入线上综合分的两处表述不一致，请明确复赛评奖、半决赛晋级及最终综合分的权重口径。

## 明确必须遵守的事项

- 只能使用 OpenAI 官方 CLIP ViT-B/32 预训练权重。
- 每阶段只使用该阶段官方数据。
- 测试集不以监督、自监督、无监督或伪标签方式参与训练、选样、调参或统计更新。
- 最终不得多模型集成、融合或投票。
- 未获书面确认前，不把“多种子分别提交并按线上榜择优”当作允许策略；多种子仅用于本地稳定性确认。
- 人工查看只能辅助理解和排错；最终筛样必须由代码自动复现。
- 数据和提交物不得泄露或用于赛事外用途。
