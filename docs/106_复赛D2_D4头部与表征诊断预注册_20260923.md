## D2：只测一次温和类均衡与一次固定 τ

1. 后训练类均衡线性头：`configs/experiment/stage2_d2_c2_features_invsqrt_p05_seed20260921.yaml`。与 D1 同 100 epoch / batch 4096 / Adam 0.01 / seed，仅增加训练分区类别频率的逆频率 `power=0.5` 权重；不同时改视觉、损失或数据采样。此机制只使用当前 Stage 2 train 分区统计。
2. 无训练 τ-normalization：在**已训练的 D1 自然 cRT**上固定 `τ=0.5`，每类权重行 `w_c / ||w_c||₂^τ`，偏置保持原值；零范数硬失败。τ 不按验证集搜索，评估产物应记录头 checkpoint、τ 与共同 C2 缓存身份。它和类均衡 cRT 是两条独立对照，不叠加。
3. 若 Top-1 与 macro 均无明显正收益，或尾类类均/零召回恶化，停止头部先验方向。若旧折改善达到约 1 pp，再在第二折**重训** H1/视觉模型确认；不能把旧 C2 直接用于第二折。

**τ=0.5 执行记录（2026-09-23）：**`artifacts/reports/stage2_d2_c2_feature_tau05_20260923.json`。同一 D1 `best.pt` 与 C2 缓存，原 cRT / τ 后 Top-1 为 **68.4064% / 53.7210%**，macro **67.5318% / 52.5261%**，tail 类均 **65.8911% / 48.2145%**，零召回 **7 / 18**。每类权重范数 min/median/max 约 26.20/33.90/40.67，偏置绝对值中位数约 0.199。按预注册的“缩放权重、偏置不变”定义，τ 使权重 logit 整体量级剧变；该点直接淘汰，不在验证集搜索 τ 或临时重定义偏置处理。**不能**由此推断所有类别先验方法无效；是否运行独立的逆频率 cRT，仍按资源审批决定。

## D4：先诊断，不直接造新模型

对原始 OpenAI CLIP 与 C2 的**同一 train/validation 样本**比较：(a) 每类训练质心的验证余弦 margin、(b) 类内/类间角度分布、(c) 训练内近邻标签一致性与冲突组敏感性、(d) 同协议线性头差值。近邻计算用预先固定的训练子样本和分块矩阵乘法，避免 `148,695²` 全量矩阵；报告样本量和抽样种子。若 C2 特征分离度明显改善但头部候选不改善，优先检查冻结头/读出；若依旧大量细粒度混淆，再考虑 `docs/104` 的 V1/V2 单变量视觉重构。

**解释边界：**C2 的监督视觉微调确实让同折未参与训练的观察标签更可分，并且这种改善横跨 head/mid/tail；原始 H1 在原始特征上的固定验证 64.4719%，同一个 H1 在 C2 特征上的 D0 为 68.4602%，也给出约 +3.99 pp 的实际线性读出收益。质心/近邻本身不是最终分类器，不可把其绝对准确率或 +10 pp 直接预测为线上涨幅。D1–D3 的换头结果均没有突破原 H1，因此“冻结头失配可由后训练线性/余弦头轻松解决”未获证实；但尚未测试非线性残差头。更重要的是，旧验证折的重复/冲突组成异常富集，且隐藏 test 的视觉分布不可见，**本实验没有解释线上 57.18 与固定验证约 68.46 的全部差距，更不能断言模型上限已到。**

**下一步决策：**停止继续扫相似的线性头超参，优先按 `docs/104` 做一个严格单变量的 V1（同官方初始权重、Stage2 H1、末六块、AC、8 epoch、seed 与旧 C2 对照；仅把头从冻结改为受控低学习率联合训练），核对 Top-1/macro/tail/冲突、有效质量和训练—验证间隙。若 V1 无强收益，再评估 V2 的 224 输入裁剪或局部 token 读出；不触碰未经规则确认的高分辨率/多裁剪方案。第二折仍须重训 H1 与视觉权重，旧 C2 绝不能跨折验收。
