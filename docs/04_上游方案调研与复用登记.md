## 1. 文档目的

本文件是项目唯一的上游方案动态台账，用来确保值得利用的成熟 GitHub 方案不会停留在聊天记录或参考文献中，也防止未经合规、许可证和资源审查的研究代码直接进入正式链路。

这里的“使用”包括：复现为正式对照、移植合规的最小机制、依据其思想独立实现，或经过证据化审计后明确排除。进入最终方案仍须依靠本项目统一实验，不以论文排行榜或 GitHub star 数直接决策。

## 2. 强制生命周期

每个已登记候选在到达强制触发阶段时必须依次经过以下流程；P0/P1 候选优先完成：

1. **登记**：记录官方仓库、论文、许可证、检查日期和当前状态。
2. **版本锁定**：首次复现或移植前记录完整 commit SHA，不使用浮动的 `main`/`master` 作为复现依据。
3. **合规审计**：检查骨干、权重、数据、类别语义、训练模型数量、最终推理和测试集使用方式。
4. **最小化提炼**：明确可独立实现的最小机制及不采用的原流程。
5. **统一实验**：绑定实验 ID、同预算基线、主指标、辅助诊断和资源开销。
6. **决策归档**：标记为 `采用`、`保留候选`、`仅借鉴` 或 `排除`，给出证据和回退方案。
7. **许可证落地**：实际复制或改写代码时更新根目录 `THIRD_PARTY_NOTICES.md` 和文件级来源注释。

P3、M1-M5 或最终复训开始前必须回查本文件。已到强制触发阶段且状态为“待审计”或“待实验”的候选不得无故跳过；若不实施，必须写明排除证据。

## 5. 候选详细登记

### 5.1 OpenAI CLIP

- 仓库：https://github.com/openai/CLIP
- 论文：https://arxiv.org/abs/2103.00020
- 维护方：OpenAI 官方
- 默认分支：`main`
- 固定 commit：`d05afc436d78f1c48dc0dbf8e5980a9d471f35f6`
- 许可证：MIT；锁定版本 `LICENSE` 已复核
- 级别：P0 必用基础
- 可用部分：OpenAI 官方 CLIP ViT-B/32 权重、图像预处理、tokenizer、模型结构和加载逻辑。
- 赛题作用：唯一正式骨干来源；所有其他方案必须适配到这一底座。
- 本地权重：`artifacts/weights/ViT-B-32.pt`；SHA-256 `40d365715913c9da98579312b702a82c18be219cc2a73407c4526f58eba950af`。该文件已被 Git 忽略。
- 禁止混用：OpenCLIP/LAION 权重、其他更大骨干或来源不清的转换权重。
- 触发/实验：P3；建立加载测试、权重 SHA-256、预处理一致性和显存/吞吐基准。
- 退出条件：无；若官方实现与当前 Python/PyTorch 不兼容，只能做保持数值一致的兼容封装，不能换权重来源。

### 5.2 DeFT

- 仓库：https://github.com/HotanLee/DeFT
- 论文：https://proceedings.neurips.cc/paper_files/paper/2024/file/6af08ba9468f0daca4b8dd388cb95824-Paper-Conference.pdf
- 默认分支：`main`
- 固定 commit：`254490a2b566e3a4fbcce937d116cf04558dabf2`
- 许可证：MIT；锁定版本 `LICENSE` 已复核
- 级别：P1 主线候选
- 核心价值：利用正/负文本提示和视觉—语言一致性估计标签可信度；论文特别讨论了细粒度数据上普通 small-loss 策略的局限。
- 拟复用最小机制：类别感知的正/负语义可信度、软权重或课程信号，以及与 PEFT 的组合方式。
- 不直接采用：原仓库完整两阶段训练脚本、特定公开数据加载器、未经审核的依赖和任何可能被解释为独立辅助模型的流程。
- 合规风险：官方若只给数字类 ID，语义提示无法直接使用；两阶段检测与适配是否允许需保守实现或询问组委会。
- 资源风险：原依赖锁定在较旧的 PyTorch/CUDA；需在当前环境重写最小模块。
- 触发/实验：M2/M3；与“类内损失 + 历史稳定性”同预算比较筛样 precision/recall、Top-1、tail accuracy 和峰值显存。
- 退出条件：无官方语义类名且视觉替代信号无增益；或三种子提升不稳定/违反单模型解释。

### 5.3 CLIPCleaner

- 仓库：https://github.com/MrChenFeng/CLIPCleaner_ACMMM2024
- 论文：https://arxiv.org/abs/2408.10012
- 默认分支：`main`
- 固定 commit：`8e06f4b917ca8110270f805e65483abcc2f37ee8`
- 许可证：MIT；锁定版本 `LICENSE` 已复核
- 级别：P1 主线候选
- 核心价值：源码直接支持 `clip.load("ViT-B/32")`，组合 CLIP 零样本语义、冻结视觉特征逻辑回归、类内 GMM 和一致性进行离线样本筛选。
- 拟复用最小机制：类内分数归一化、按类双峰建模、零样本/视觉一致性交集及每类最低样本保护。
- 不直接采用：完整下游训练流程、外部数据集配置、大模型/RN50 分支和数据集专用人工属性描述。
- 合规风险：实现依赖 `class_names`、`detailed_features` 和 prompt；只允许使用官方提供的类名，不能补充外部物种描述。
- 资源风险：全量 `N×K` 相似度在 1,500 类阶段成本较高，应分块计算并只落盘必要分数。
- 触发/实验：M2/M3；先在合成噪声夹具验证类内筛选，再在官方训练划分与视觉原型路线比较。
- 退出条件：无合规语义类名且视觉 LR/GMM 不优于简单可信度；或内存/时间成本不成比例。

### 5.4 JoAPR

- 仓库：https://github.com/yunncheng/JoAPR
- 论文：https://openaccess.thecvf.com/content/CVPR2024/html/Guo_JoAPR_Cleaning_the_Lens_of_Prompt_Learning_for_Vision-Language_Models_CVPR_2024_paper.html
- 默认分支：`main`
- 固定 commit：`ffe5fdb23a48a6e0adb6a2a403c6b2f84d5476fb`
- 许可证：MIT；锁定版本 `LICENSE` 已复核
- 级别：P2 备选模块
- 核心价值：联合自适应样本划分与标签修复，面向噪声标签下的 CLIP Prompt Learning。
- 拟复用最小机制：类别自适应阈值、可信/不可信划分、严格受控的软标签修复。
- 不直接采用：默认 RN50/CoOp/少样本数据配置和整套 Dassl 训练栈。
- 合规风险：Prompt 分支依赖官方语义类名；标签修复容易放大自确认偏差。
- 触发/实验：仅在 M1-M4 稳定后进入 M5，与“不修标签、只做软权重”比较。
- 退出条件：软权重尚未稳定、阈值敏感、尾类退化或只有单次榜单收益时立即停止。

### 5.5 ELR

- 仓库：https://github.com/shengliu66/ELR
- 论文：https://proceedings.neurips.cc/paper/2020/hash/ea89621bee7c88b2c5be6681c8ef4906-Abstract.html
- 默认分支：`master`
- 固定 commit：`934af53434a336b6db80d05d7649d23216e8ca6d`
- 许可证：MIT；锁定版本 `LICENSE` 已复核
- 级别：P2 备选模块
- 核心价值：通过每样本历史预测的早期学习正则抑制对噪声标签的记忆，可保持单模型训练和单次推理。
- 拟复用最小机制：ELR 正则思想和状态更新；根据 8 GiB 显存改为 CPU/半精度、top-k 或低内存状态设计。
- 不直接采用：ELR+ 或任何多模型扩展、CIFAR 专用训练脚本。
- 资源风险：约 297,282×1,500 的完整 float32 状态约 1.66 GiB（不含框架开销），必须先完成内存设计。
- 触发/实验：P2 合成噪声逻辑验证；P3 冻结特征或 PEFT 低成本消融。
- 退出条件：状态压缩损害方法定义，或成本明显高于收益。

### 5.6 LogitClip

- 仓库：https://github.com/hongxin001/LogitClip
- 论文：https://proceedings.mlr.press/v202/wei23e.html
- 默认分支：`main`
- 固定 commit：`7e45730b0073b6ba9af2d2af574300d42d50fcee`
- 许可证：锁定版本根目录无 `LICENSE`（GitHub 内容 API 返回 404）；禁止复制源码，除非上游以后明确授权且重新审计
- 级别：P2 备选模块
- 核心价值：训练时限制 logits 范数，机制简单、单模型、推理无额外分支，适合作为便宜鲁棒损失对照。
- 拟复用方式：根据论文公式独立实现，不复制无明确许可证的仓库代码；添加边界值、梯度和 AMP 单元测试。
- 触发/实验：P2 验证数值行为；P3 与 CE、GCE 同预算比较。
- 退出条件：无法从论文充分还原、数值不稳定或无稳定增益。
