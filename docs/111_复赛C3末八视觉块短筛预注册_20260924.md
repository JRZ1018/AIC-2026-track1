## 为什么做这一轮

C2 从末四块增加至末六块，在旧固定折三种子配对 Top-1 平均 +0.7869 个百分点，全量单模型线上由 56.4950 升到 57.1814。V1 联合训练头收益不足，V2 patch 均值头不足；本日不重训换用 letterbox 推理的诊断又降低 9.51 个百分点。这些证据支持继续测试**视觉可训练容量**，但不能假定末八块必然更好，更不能把旧折收益当作线上收益。

## 单变量、对照与边界

使用同一 Stage2 旧固定 split、同一全新 Stage2 H1、同一官方 OpenAI CLIP ViT-B/32、seed `20260921`、AC、batch 64、8 epochs、视觉 lr `1.75e-6`、冻结分类头、224 中心裁剪与其余数据增强；唯一改动是视觉解冻深度由 `last_n_blocks=6` 改为 `8`。对照 C2 运行 `20260923-stage2-day3-c2-last6-ac-8ep-seed20260921` 的同 epoch 指标和最佳指标分别比较，不混用。该旧折有重复/冲突偏置，故只供短筛，不能单独批准全量出包。

预设晋级条件：在 epoch 8 配对 Top-1 至少 +0.3 个百分点，macro 和 tail 类均召回均不下降，零召回类不增加，AC 尾类有效质量不跌入 L2；否则停止 C3。若通过，另报资源预算，在第二折将 C2/C3 从官方 CLIP 和该折新训 H1 出发分别重训做独立确认（旧折 C2 checkpoint 见过第二折部分验证图，禁止直接跨折评估）。通过确认后才冻结 14/16-epoch 全量方案和 test 一次推理，不做融合、投票或 test 选模。
