# P17：训练权重 EMA 折2单变量短筛预注册（2026-09-30）

## 决策与假设

P14起点锚定、P15视觉OT、P16固定六视图已按事前门禁失败止损。P13两折8→14轮虽通过，但与旧P7全量配方相同，不能证明新线上提分。P17只检验训练轨迹的指数滑动平均（EMA）能否提高同一单模型的泛化；这是假设，不是已证收益。不使用额外数据、教师、蒸馏、模型集成或test信号。赛题要求官方OpenAI CLIP ViT-B/32、单模型、仅官方阶段数据且test只作最终推理。

## 冻结单变量和对照

候选 `configs/experiment/stage2_p17_fold2_sce_ac_ema0999_8ep_4090.yaml` 与已验同机P13折2 8轮对照 `configs/experiment/stage2_p13_fold2_sce_ac_8ep_4090_control.yaml` 的解析配置，仅run_id、output_dir和 `trainable_ema: {enabled: true, decay: 0.999}` 不同。EMA在训练前从可训练参数初始化，**仅在AMP未跳过优化器更新时**对全部可训练参数按 `shadow=0.999*shadow+0.001*raw` 更新。优化器始终用原始权重；SCE、AC、训练样本顺序、336、末8块、冻结头、seed、LR和8轮日程不变。每轮先对原始权重作原有固定分区验证并记录，随后临时换入EMA验证并无条件恢复原始权重；以EMA单视图Top1选唯一best，最终固定384四视图也只用该**单一EMA检查点**。不对EMA与原始权重平均预测、不选择有利的decay/epoch/视图。全量若获准晋级，固定8轮最终EMA，不借验证选轮。

训练前必须CPU测试EMA数值、冻结参数排除、异常时原始权重恢复、safe CPU checkpoint加载、配置单变量比较；记录每文件SHA。训练后需检查候选原始权重每轮单视图验证与同机P13对照的差异，以发现EMA实现意外改变训练轨迹；若原始轨迹异常则实验无效，不据此宣称收益。严格完整8/8、AC每轮非L2、损失有限、无零采样类、best/last在CPU `weights_only=True`加载，last含优化器/调度器/scaler/RNG/AC/EMA状态及更新次数，否则止损。
