# P11：NCE+RCE 单变量损失配对筛选

日期：2026-09-29（Asia/Shanghai）。这是在本机 RTX 4060 上进行的一折 train-derived validation 短筛，不是提分保证，也不是全量/提交授权。

## 唯一问题与假设

此前 SCE 配方在固定 336、末 8 个视觉块、AC 条件下只有很小的离线增益；诊断中其有限梯度范数多数超过 clip=1。候选假设：基于类别和归一化损失构造的 NCE+RCE 主动/被动组合可能比现有 SCE 更适合本任务。Ma et al.（ICML 2020）提出 NCE+RCE 作为 active-passive loss；论文也警告单独 NCE 等归一化鲁棒损失可能欠拟合，因此本次只检验 NCE+RCE 组合。论文结果来自不同骨干/数据，不能外推为本赛事预期分数。

## 配对定义

- 对照：固定 `SCE(alpha=0.1,beta=1,A=-4)`。
- 候选：`NCE+RCE(alpha=750,beta=0.1,A=-4)`。论文 WebVision 配置使用 50 类、NCE alpha=50；本赛 750 类的候选将 alpha 按类别数比例缩放至750，以补偿 NCE 分母包含750个类别损失这一维度差异。这个单点缩放在本数据上未经验证，禁止扫参。
- 两组均从折2同一 Stage2 train-only H1 `20260925-stage2-fold2-c5-h1-336-seed20260921/best.pt` 初始化；同一 Stage2 折2固定 118,958/29,737 split、官方 OpenAI CLIP ViT-B/32、336位置插值、末8块、batch64、seed20260921、AC、增强、optimizer、LR、clip=1、8轮；仅损失配方不同。为排除硬件漂移，SCE 对照在本机4060重新匹配运行，不用历史 A10 运行代替。
- 仅使用 Stage2 官方 train 分区训练，所有选模指标来自固定 train 派生验证；不打开或索引 test。

## 预注册指标与晋级

主口径为每个8轮训练按中心验证Top-1选出的best，在同一固定384四视图单checkpoint诊断上配对比较；同时报告中心Top-1、四视图Top-1、macro、tail类均召回、非跨标签精确重复普通组、近重复组 paired bootstrap（500次，seed20260925）及每轮AC/梯度诊断。

候选只有同时达到以下短筛门槛才进入新一折确认：四视图 Top-1 增益 `>= +0.30pp`；近重复组 bootstrap 95%下界 `>0`；macro 增益 `>=0`；tail类均召回增益 `>=-0.25pp`；普通组增益 `>=0`；完整8轮、全部29,737验证行、来源SHA匹配、中心指标与训练metrics一致且AC全程非L2。未通过则止损此配方，不扫 alpha/beta/log_zero、种子或同类变体。

一折通过不自动授权全量模型或 test。至少还需另一折相同单变量配对确认、跨折正向且无保护指标退化，然后从项目正式晋级规则审查全量复训所需证据；只有 train-only证据能证明某个方法优于当前单checkpoint时才考虑一次最终test推理。不得按线上分反向调参。

配对顺序串行执行，共用 `artifacts/queues/training.lock.json`；启动前要求>=12GiB磁盘、>=5GiB当前可用显存，预计2.5–4小时4060 GPU墙钟、高峰额外磁盘2–4GiB，硬上限6小时。每轮canonical `last.pt` 原子更新，配对中止时保留输出与锁现场；只有人工确认进程退出及精确token后才可清陈旧锁，恢复另用原配置与该run的完整last。不得删除任何数据、权重或历史checkpoint。无test路径进入任务配置/代码。

实现依据为 Ma et al., *Normalized Loss Functions for Deep Learning with Noisy Labels*, ICML 2020, [PMLR 119](https://proceedings.mlr.press/v119/ma20c.html)。本项目仅独立实现论文公式，没有复制作者代码；基础 ELR 是不同候选，不与本次叠加。
