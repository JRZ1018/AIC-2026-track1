## 使用边界

- 参考源码不进入比赛工程的 import 路径。
- 不直接从上游目录运行训练。
- 不修改上游快照；需要实现时在主项目中编写最小模块。
- 实际复制或改写 MIT 代码时创建 `THIRD_PARTY_NOTICES.md`。
- 无许可证仓库只阅读论文和思想，不复制源码。
- 更新到新 commit 前必须重新进行许可证、权重、数据、模型数量和推理路径审计。
