# 原冻结推理源码快照

本目录是正式测试推理阶段使用的原源码，按执行时状态冻结保存。

- 推理流程：构造官方 CLIP 图像编码器，严格加载 `final.pt` 的视觉与分类头参数，对同一 checkpoint 执行固定四视图（原生 336、原生 336 水平翻转、短边缩放到 384 后中心裁剪 336、以及其水平翻转）并等权平均 logits，再执行固定 k 近邻图平滑与类别均衡后处理。
- 结果契约：根层只含 `pred_results.csv` 的 ZIP，37,444 个唯一官方 JPG 文件名与官方 750 类四位映射，逐字节与 CRC 均校验。
- 推理阶段不更新模型参数。
- 当前复现使用 `AIC-2026-43080930-代码与数据/scripts/infer.py`、`validate.py` 与 `postprocess.py`；`reproduction_cache/` 保存了本次正式推理的冻结 logits 与特征，可在无图片条件下复现后处理结果。文件内的历史绝对路径是当时的执行记录。
