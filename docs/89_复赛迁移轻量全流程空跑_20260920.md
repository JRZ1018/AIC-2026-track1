## 3. 提前发现的问题

第一次执行在训练启动前被 B07 守卫拦截：非提升权限 shell 无权调用 Windows CIM 枚举全系统
Python 进程，守卫按设计 fail closed；锁自动释放，GPU 未启动。删除这次由本批生成的精确失败
目录后，以提升权限重跑成功。

因此本机正式训练/空跑的操作要求冻结为：保留全系统进程探测，不允许降级；入口需要以能访问
`Win32_Process` 的提升权限运行。若 CIM 再失败，任务立即停机。
