## 3. 下载、验签与解压 runbook

1. 在平台记录官方 URL、文件名、声明大小、下载开始时间和账号责任人，不记录 Cookie/Token。
2. 优先使用支持续传的浏览器或 BITS；中断后续传到同一 `.partial` 文件，完成前不改名。
3. 下载完成立即记录字节数与 SHA-256：

```powershell
Get-Item D:\stage2-download\archive.zip | Select-Object Name,Length,LastWriteTime
Get-FileHash D:\stage2-download\archive.zip -Algorithm SHA256
```

4. 原始包设只读并保留到数据、数量、图片解码和哈希全部验收；不得直接解压覆盖 Stage 1。
5. 先解压到唯一临时目录 `D:\stage2-extract\<archive-hash-prefix>`。解压失败时保留原包和日志，
   只删除已确认的该临时目录，再重试；禁止对宽泛路径递归删除。
6. 统计 train/test/类别、检查样例结构和坏图，全部通过后才移动为 `DataSetStage2`。
7. 记录最终目录、原包和关键 manifest 哈希；任何二次下载都作为新来源重新验签。
