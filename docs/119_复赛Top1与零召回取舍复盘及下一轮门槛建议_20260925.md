## 真实观察

赛事主指标是总体 Top-1。C6 在同一折配对的两套 Stage2 train 派生验证图上，匹配336+固定翻转 TTA 相对 224 C3+同一 TTA 的 Top-1 分别高 **+1.8428/+1.9740 pp**，macro 高 +1.7849/+1.9938 pp、tail 类均高 +1.7134/+1.8738 pp。旧折逐样本配对新方案净胜 `1736−1188=548` 张，新折 `1796−1209=587` 张。复用项目既有 `grouped_bootstrap_delta`，把每个近重复组或无组单例作为成对抽样单位、固定种子 `20260925`、500 次重采样，95% 描述性区间分别为 **+1.44 至 +2.24 pp**、**+1.61 至 +2.34 pp**，21,680/28,091 个组。报告在 `artifacts/reports/20260925-c6-fold1-paired-near-bootstrap.json` 和 `20260925-c6-fold2-paired-near-bootstrap.json`；代码 `scripts/audit_stage2_paired_tta_gain.py`，相关 CPU 测试 4/4 通过。区间仅条件于固定模型和有噪观察标签，不包含重训方差或隐藏 test 偏移；两折验证集合也约有自然重叠。

然而旧折零召回 `2→4`，触发 C6 预注册否决。两类新增零召回是内部类 `589`、`671`：该折验证各有 10、8 张，官方 train 全量各有 49、41 张；C3+TTA 在这两类各答对 **1 张**，C5+TTA 各答对 **0 张**。从旧折已观察的 Top-1 计，这一硬否决实际由 29,737 张中的两张差异触发，约 **0.0067 pp**，同时舍弃了净 548 张、+1.8428 pp 的总体收益。这个分析解释门槛敏感性，不否定这两类在未知 test 上可能有更大风险，也不能用它反推 test 标签。

C7 同 checkpoint 四视图相对双视图在两折分别 +1.0862/+0.6894 pp，macro/tail 类均均正向；旧折零召回 `2→5`，新增类 `413`、`589`、`671` 的验证数为 4、10、8。C3 双视图对三类各答对一张，C7 四视图各为零。相似现象重复出现：局部尺度/高分辨率可能在总体与少数弱类之间存在真实取舍，但“零召回计数增加”比 class-mean 与主指标剧烈跳变得多。C7 也仍按原门槛失败，不访问 test。

C7 旧折四视图相对双视图的近重复组配对 bootstrap 描述性区间为 **+0.47 至 +0.95 pp**，报告 `artifacts/reports/20260925-c7-fold1-paired-near-bootstrap.json`。这强化了固定验证集上的总体收益证据，但**不**改变它因零召回门槛失败的状态，也不证明 test 会同幅度上涨。

## 对当前决策的判断

将零召回**任何 +1**设为一票否决，与官方 Top-1 和冲分目标未必匹配。750 类、每类验证支持数不均，一张样本即可让某类从非零跳为零；旧折又已知近重复/冲突富集。另一方面，不能因为观察到 C6 主指标好，就把今天的硬门槛事后抹去，或把 +1.9 pp 验证增益直接当作线上分数预测。最稳妥的表述是：**目前存在一条高潜力、尚未通过当前风险偏好的 336 单模型路线；不是已获准出包的方案。**
