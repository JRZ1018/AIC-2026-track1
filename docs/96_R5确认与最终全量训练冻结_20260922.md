# R5 确认与最终全量训练冻结

更新时间：2026-09-22（Asia/Shanghai）

## 1. R4 门禁结论

R4-4（尾部平均权重地板 0.35）与 R4-5（每类有效质量总和地板 4.0）均完成 8 轮，未触发 L2，采样零类为 0。R4-4 的最终指标为 Top-1 0.6762282848、macro 0.6685663441、tail 0.6687299013、零召回 3；R4-5 为 Top-1 0.6759592295、macro 0.6680623572、tail 0.6673195958、零召回 4。

按预注册门禁，两者相对 R3 第 8 轮（Top-1 0.679860115、macro 0.671815040）总体 Top-1 和 macro 均下降超过 0.25 个百分点，故不晋级。R4 的结论是“保护机制保持 L1，但当前保护强度带来总体性能代价”，不能据此直接替换 R3。

## 2. R5 唯一候选

R5 只确认 R3 AC 配方：末四视觉块 PEFT、冻结头、batch 64、视觉学习率 1.75e-6、weight decay 0.01、clip 1.0、16 轮、AC warmup 1 / momentum 0.8 / history mix 0.5 / `min_weight=0.02` / `magnitude_mix=0.75`。R4 保护参数不进入最终配方。

先以同一 Stage2 H1、同一 split 做 seed `20260922` 与 `20260923` 的 8 轮短确认；只改变训练随机种子，不平均、不融合、不投票。确认门禁：有效质量不得达到 L2；Top-1、macro、tail 不得相对 R3 第 8 轮下降超过 0.25 个百分点；零召回类不超过 4。任一候选失败即淘汰该种子，R3 仍为算法基线。

## 3. 最终全量顺序

确认通过后严格串行：

1. 从官方 CLIP 的 Stage2 全量特征缓存重训全量 750 类 H1（148,695 条，100 轮）；
2. 以该全量 H1 `final.pt` 初始化唯一一次全量 AC PEFT（16 轮）；
3. 锁定唯一 checkpoint；
4. 对 37,444 张 test 只推理一次，构建 `pred_results.csv` 与 ZIP；
5. 记录 config、环境、输入 manifest/split/mapping、H1 与 PEFT checkpoint、CSV/ZIP 哈希。

固定验证 H1 `best.pt` 只用于 R5 短确认，不能作为最终全量初始化器；初赛任何权重、特征、阈值、逐样本状态均不进入 R5。

## 4. 合规边界

最终只提交单模型预测；不做种子平均、模型融合或投票；test 在最终锁模前不访问。R5 失败时回退到 R3 配方，不因单一 Top-1 指标事后放宽门禁。
