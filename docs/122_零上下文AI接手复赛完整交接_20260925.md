## 6. 规则与方法的不可跨线标准

1. 骨干严格是官方 OpenAI CLIP **ViT-B/32**，只用其官方权重；不能用 ViT-B/16、Swin、DINOv2、OpenCLIP/LAION 权重，不能改内部注意力拓扑冒充原骨干。可参考论文思想，不能导入不合规预训练资产。
2. **Stage2 train-only** 用于训练、特征缓存、折内验证、TTA 视图/权重选择和统计。Stage2 test 只可在最终方案冻结后推理；禁止自监督/伪标签适配、阈值选择、错误分析或看线上分反推标签。
3. 最终单模型、单 checkpoint、单推理流程。固定确定性多视图对**同一个模型**求 logits 均值获群聊许可；多个 checkpoint、种子平均、权重融合、投票不行。任何 TTA 视图、顺序、缩放、裁剪、插值、聚合权重必须在验证结果前预注册。
4. 当前 336 实现 `src/aictrack1/models/clip_resolution.py` 仅对位置网格做 7×7→10×10 bicubic 插值，CLS 和官方参数名/权重保留，原始 patch stride32 导致右/下各16像素未参与卷积。**该代码目前只允许 336，不支持直接改配置为 320。**未来 320 必须实现、测试和匹配训练；仅改已有权重的推理分辨率曾使 Top-1 下降约 1.77 pp。
5. 官方线上主指标是 Top-1。macro、tail 类均、按支持数分桶、逐类零召回、AC 每类权重均值/sum(weight)/有效质量必须并列报告。未来不设“任何新零召回一票否决”，但数据映射错误、组泄漏、来源污染、AC 有效质量 L2、整片尾类明显塌陷等属于停止条件。
