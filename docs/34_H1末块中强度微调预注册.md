# H1 末块中强度微调预注册

日期：2026-09-13

## 假设

注意力 LoRA 从一层、两层到 rank-8 的增益逐步缩小，Attention+MLP rank-4 也仅比匹配基线提高 0.0097 点，说明约十万参数的轻量适配已接近当前上限。本候选把训练强度提高到最后一个完整视觉 Transformer 块，并保留 `ln_post` 与投影，约 748 万个视觉参数；分类头继续冻结，避免此前“最后块 + 联合更新头”对照中的混杂和头部漂移。

## 冻结设计

- 初始化：H1 线性头与 OpenAI CLIP ViT-B/32。
- 唯一方法包：`last_block`，视觉学习率 `3e-6`、固定 3 epochs、分类头学习率 0。
- 与旧失败 B2 的关键区别：旧实验从 A1 余弦头出发、视觉学习率 `1e-5` 且联合更新头；本次从已被榜分验证的 H1 出发、冻结头并将视觉学习率降至三成。
- 不使用额外数据、测试统计、伪标签或多模型；最终仍是单模型、单前向。

参数白名单与 CUDA 资源 smoke 已通过；用户随后批准了正式 seed1 资源预算，因此配置已切换为 `execution_enabled: true`。正式筛选预计 20–30 分钟、峰值显存低于 1.5 GiB、磁盘新增约 80–150 MiB、每 epoch 可恢复。

## 预检结果

- CUDA smoke 已通过，设备为 RTX 4060 Laptop GPU；未访问测试集。
- 实际可训练视觉参数为 7,482,624；白名单仅包含 `proj`、最后一个完整视觉块与 `ln_post`。
- 128 个受限样本、4 steps 的峰值显存为 555.41 MiB，吞吐为 88.52 samples/s。
- smoke 检查点 SHA-256：`b27c633a10fd2a1c9d283367b6e10948f4a5fd264787c3ae1191de955e321f6b`。
- 正式任务仍按更保守的 20–30 分钟、峰值低于 1.5 GiB、磁盘新增 80–150 MiB 申报。

Seed1 晋级门槛：相对当前最强固定验证候选 rank-8 的 69.2185% 至少提高 0.20 点，且 macro/冲突子集无明显退化。未过门槛则不以延长 epochs 补救，转向单模型 MixUp/增强路线。
