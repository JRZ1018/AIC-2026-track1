# 原 FULL 训练源码快照

本目录是最终视觉联合训练阶段使用的原训练源码，按执行时状态冻结保存。

- 入口：`scripts/train_n1_peft.py`，配置在 `configs/`，输入契约在 `inputs/`，科学实现在 `src/aictrack1/`。
- 相对基线配方 J5 的唯一科学变量是视觉学习率 `3.5e-6`；分类头学习率 `5e-6`、SCE `α=0.1`、置信度加权、336 输入、AdamW 与余弦 20 轮均与 J5 一致。
- 训练从官方 CLIP 权重与全量训练集上固定 100 轮的分类头初始化出发，使用全部 148,695 张官方训练图、0 张验证图，seed `20261010`，固定第 20 轮导出单个模型。
- 当前复现不直接运行本目录，而是使用 `AIC-2026-43080930-代码与数据/scripts/train.py` 与 `portable_training/` 的便携入口，它们复用本目录的科学实现并改用作品根相对路径。文件内的历史绝对路径是当时的执行记录。

第三方来源与许可见 `AIC-2026-43080930-代码与数据/THIRD_PARTY_NOTICES.md`。
