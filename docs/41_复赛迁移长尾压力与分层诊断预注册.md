## 3. 长尾压力划分协议（预注册）

配置：`configs/data/long_tail_stress.yaml`；构造器：`scripts/build_long_tail_split.py`；输出在 `artifacts/audits/stage1/train/`。

- 数据范围：只用**初赛训练部分的固定 train 划分**（82,592 张），不使用 validation，不读取 test。
- 分层规则：按 train 划分内每类样本数降序排序，类索引作为并列打破规则；head 20%、mid 30%、tail 50%，即 100/150/250 类。
- 长尾调度：head 保留 100%、mid 20%、tail 5%，每类至少保留 1 张；评估划分从每类剩余样本中取 15%。
- 不可拆分单元：近重复簇（`near_duplicate_group`）与精确重复簇必须整体落在同一侧；构造后必须重新统计跨侧簇数为 0。
- 随机性：所有选择由 `seed = 20260915` 与 `sha256(seed + sample_id)` 决定，不使用文件系统顺序。
- 保留率定义：`reference_count` 为 train 划分内该类原始样本数，`kept` 为长尾训练侧样本数；两者都是**设计值**。训练期自动筛样导致的二次保留率属于后续机制验收，不由本划分代替。

保留率门禁（构造期即判定，不因结果放宽）：

- 无任何类被饿死（`starved_class_count == 0`）；
- 全体每类保留率最小值 ≥ `0.0100`；
- tail 平均保留率 / head 平均保留率 ≥ `0.0400`（按预注册 5% / 100% 的调度，实测值因整簇不可拆分与取整会略低于 0.05）。

head−tail 准确率差门禁：诊断报告中的 head 与 tail 分层准确率差 ≤ `0.7000`。该门禁用于发现“尾类几乎全错”的失效模式，不作为选模指标。

## 4. 诊断协议（预注册）

指标定义：

- 分层准确率：某分层全部评估样本的 Top-1；
- 类均准确率：该分层内每个有评估样本的类的召回均值（等价于分层 macro）；
- 最差类召回：该分层内有评估样本的类的最小召回，并记录类索引与支持数；
- 零召回类数、召回 p10/中位/p90；
- head−tail 准确率差与类均差；
- 每类保留率：全体最小值/均值、按分层的均值/最小值、饿死类与仅剩 1 张的类。

评估入口：`scripts/diagnose_long_tail.py`，唯一一次只读前向，输出 `artifacts/reports/20260915-long-tail-diagnostics/`。

首个诊断模型固定为当前线上最佳 **rank32/alpha64 全量三轮 `final.pt`**。必须同时报告：

1. 固定 noisy-validation 参照（均衡，20,626 张）——用于确认诊断口径与既有 68.x% 基线一致；
2. 长尾评估划分（9,823 张，每类约 25 张）。

**适用边界（必须写进结论）**：长尾评估划分取自 train 划分内的样本，该 checkpoint 已在全量训练中见过它们，因此长尾数字是**乐观上界**，只能用于工程口径验收与失效模式排查，不能当作无泄漏泛化或选模依据。真正的长尾压力测试需要一次**仅用长尾训练划分从头训练**的冻结特征头，该训练属于新资源预算，须单独批准。

## 6. 真实长尾压力测试协议（2026-09-15 追加）

第 4 节的固定头诊断只是工程口径验收。真正的压力测试是**仅用长尾训练划分从头训练**冻结特征头，协议如下：

- 训练数据：长尾训练划分（23,880 张、500 类；head 16,912 / mid 4,967 / tail 2,001）。
- 训练配置：线性头、Adam、`lr 0.01`、batch 4096、100 epochs、`seed 42`、固定 epoch 选择 `final.pt`（不做验证集选择），与 H1 配方完全一致，只更换训练子集。
- 两个对照必须同时报告，且三者只在“类频分布”或“每类样本数”上不同：

| ID | 训练子集 | 每类样本数 | 目的 |
|---|---|---|---|
| L1 长尾压力头 | 长尾训练划分 | 249 类 8 张、131 类 33 张、约 100 类 168–170 张 | 复现复赛的类频偏斜 |
| L2 支持数匹配对照 | 同一长尾池中每类恰好 8 张 | 全部 500 类 8 张 | 固定最稀缺类的样本数，只去掉类频偏斜 |
| L3 预算对照 | 冻结 train 划分中每类恰好 20 张 | 全部 500 类 20 张 | 预算中间点，排除“训练样本太少导致整体退化” |
| H1 参照 | 冻结 train 划分全部 82,592 张 | 每类 161–170 张 | 既有最强冻结参照 |

- 评估划分：固定 noisy-validation（20,626 张，每类 40–43 张）与长尾评估划分（9,823 张）。两者都只作诊断，不替代选模。
- 主结论指标：tail 分层准确率、tail 最差类召回、零召回类数；并按训练支持数分桶（1 / 2–4 / 5–8 / 9–16 / 17+）报告类均召回，用于直接观测“样本被筛光”的失效模式。
- 本人工压力协议的停止线：若最稀缺桶（≤8 张）类均召回低于 0.30，或零召回类数超过 25，则判定当前流程会在该构造下饿死尾类；只有复赛真实分布达到相应触发条件时，才要求先补“每类最低保留 + 类感知阈值”机制。

本节只追加协议；实测结果见 `docs/42_复赛迁移长尾压力与分层诊断验收.md`。
