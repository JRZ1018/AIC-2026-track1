# 复赛长尾判定预注册

更新时间：2026-09-20（Asia/Shanghai）

对应批次：B09

状态：**判定能力已冻结；真实复赛结论待数据到手后生成**

## 1. 原则

初赛全量训练清单为 500 类、103,218 张，每类 201–213 张，实测判为 L0；这证明初赛近似
均衡，不代表复赛。`docs/42` 的长尾结果仍只作为人工压力回归。

判定只读取当前阶段 train 标签和训练期诊断，不读取 test 内容、预测分布或线上结果。判定本身
不会自动启用算法，L1/L2 只解锁后续单变量工作包。

## 2. 冻结指标与阈值

支持分布固定报告 min、p1、p10、median、p90、max、max/min、min/median、p10/median、Gini、
effective number、零样本类和无法同时保留至少一张训练/验证样本的类。

- L0：没有触发以下门槛；保持自然采样，只记录诊断。
- L1：min/median `<0.50`、p10/median `<0.70`、max/min `>3`、Gini `>0.25`，或存在少量
  无法安全切分类；只允许一个温和采样或单一先验校正变量。
- L2：零样本类、min/median `<0.10`、p10/median `<0.25`、max/min `>20`，或无法安全
  切分类占比 `>=5%`；优先处理最低有效类质量和类感知降权预算。

训练期另报每类平均 loss、平均权重、`sum(weight)`、有效/原始质量比、降权率、采样次数、
recall 和零召回。任一类有效/原始比 `<0.10` 或 p10 `<0.25` 判为 L2；min `<0.35` 或
p10 `<0.50` 判为 L1。支持分布与有效质量取更严重的等级。

## 3. 固定命令

```powershell
.\.venv\Scripts\python.exe scripts\report_long_tail_readiness.py `
  --manifest artifacts\audits\stage2\train\samples.csv `
  --class-mapping artifacts\audits\stage2\metadata\classes.csv `
  --output-json artifacts\reports\stage2-long-tail-readiness.json `
  --output-md artifacts\reports\stage2-long-tail-readiness.md
```

同一输入必须产生 byte-identical JSON。真实数据报告必须记录每个触发项，人工确认后才更新
配置或启动 LT1–LT4。
