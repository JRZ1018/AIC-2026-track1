# 第一批 seed1 短筛预注册（CE 学习率平衡点与高学习率稳定化）

日期：2026-09-16
上游交接：`docs/52_新AI交接_当前最佳58.8577与后续追分方案.md` 第 5、6、7 节

## 1. 本轮要回答的问题

已验收证据显示一个明确矛盾（见 `docs/53_lr175e6三种子门禁失败验收.md`）：

| 学习率 | 三种子 Top-1 均值 | 三种子 macro 均值 | 三种子冲突子集均值 |
| ---: | ---: | ---: | ---: |
| 1.5e-6 | 0.705468833 | 0.705364744 | **0.308813790** |
| 1.75e-6 | **0.706616263** | **0.706502338** | 0.306604813 |
| 差值 | +0.001147 | +0.001138 | **−0.002209** |

**整体 Top-1 随学习率上升，跨标签冲突子集却系统性下降。**
本轮不再扩大统一学习率搜索范围，而是回答两个具体问题：

1. 在 1.5e-6 与 1.75e-6 之间是否存在一个**同时**提高 Top-1 且保住冲突指标的 CE 平衡点？
2. 在已被证明 Top-1 更高的 1.75e-6 上叠加 classwise history 软权重，能否**修复冲突退化**？

## 2. 三个候选（唯一变量原则）

公共定义：`training_scope: fixed_split_validation`；初始化器为只在固定 train 分区训练的
无泄漏 H1 `best.pt`（`e85d53d446fef914c7cec74faa1ede792b7774bb71ec057dee2b551d6cf485af`）；
T2 `last_n_blocks` / 末 4 个完整视觉块；冻结分类头（`head_learning_rate: 0.0`）；
batch 64；workers 4；seed `20260910`；weight decay `0.01`；gradient clip `1.0`；6 epochs；
同一 manifest / split / label conflicts / class mapping / OpenAI CLIP ViT-B/32 权重；不访问 test。

| 执行角色 | 配置文件 | 唯一变量 | 实验问题 |
| --- | --- | --- | --- |
| A | `p3_stage1_h1init_t2_last4_lr16e6_6ep_seed1_a.yaml` | visual lr `1.60e-6` | 能否优于 lr1.5e-6 且保住冲突指标 |
| B | `p3_stage1_h1init_t2_last4_lr165e6_6ep_seed1_b.yaml` | visual lr `1.65e-6` | 高学习率收益从何处开始破坏冲突指标 |
| C | `p3_stage1_h1init_t2_last4_lr175e6_cwh_6ep_seed1_c.yaml` | 增加 classwise history 软权重 | 能否恢复 lr1.75e-6 的冲突表现并保留整体收益 |

C 候选的软权重参数（沿用已实现、已有单测的 `ClasswiseHistoryWeighting`）：

```yaml
confidence_weighting:
  enabled: true
  warmup_epochs: 1
  momentum: 0.8
  history_mix: 0.5
  min_weight: 0.2
```

C 的同学习率对照是 lr1.75e-6 CE 的三种子已有结果（Top-1 均值 `0.706616263`、
macro `0.706502338`、冲突 `0.306604813`），不得与其他代初始化实验直接比较。

配置差异由 `tests/test_t2_lr_balance_plan.py` 锁定：除 run_id、output_dir、
`visual_learning_rate` 与 `confidence_weighting` 外，三项必须完全一致。

## 3. seed1 门禁（运行前冻结，结果出来不得修改）

基线为已验收的 T2 last4 / lr1.5e-6 seed1：Top-1 `0.705517292`、macro `0.705408096`、
冲突子集 `0.308813781`；以及 lr1.75e-6 seed1：Top-1 `0.706632435`、macro `0.706513941`、
冲突子集 `0.306163013`。

候选进入多种子确认必须**同时**满足：

| # | 条件 | 阈值 |
| ---: | --- | --- |
| 1 | 最佳固定验证 Top-1 | **严格高于** `0.705517292` |
| 2 | macro accuracy | **不低于** `0.705408096` |
| 3 | 冲突子集 Top-1 | **不低于** `0.308151096` |
| 4 | 最佳结果不是单 epoch 异常尖峰 | 需 epoch 曲线支撑 |
| 5 | 指标全部有限 | 无 NaN / Inf |
| 6 | 哈希一致 | config、输入、初始化器、checkpoint、commit |
| 7 | 未访问 test | `scope` 声明且 `command.txt` 无 test 引用 |

> 第 3 条阈值口径说明：阈值取 `docs/52` 第 7 节写定的 `0.308151096`。
> 该值相对 lr1.5e-6 冲突基线 `0.308813781` 容忍 −0.000663，相对 lr1.75e-6 seed1 的
> `0.306163013` 则要求回升 +0.001988，即"允许轻微回退、但不接受 lr1.75e-6 级别的退化"。
> 它与 `docs/52` 第 9 节三种子门禁使用的 `0.308801864` 属于同一冲突基线口径
> （`0.308801864` = lr1.5e-6 三种子冲突均值 `0.308813790` − 0.002），两者不冲突：
> seed1 用较宽的单种子线，三种子用更严的均值线。
> 该值在本轮运行前写定，不随后续结果调整。

### 选择规则

1. 先排除任何保护指标（第 2、3 条）失败者；
2. 合格者按 Top-1 从高到低排序；
3. **最多晋级两个**候选进入 §4 多种子确认；
4. 若无候选通过，进入 `docs/52` 第 10 节的分层学习率路线；
5. 结果出来后不得修改上述任何门槛。

## 4. 晋级后的多种子确认门禁

seed1 `20260910`、seed2 `20260911`、seed3 `20260912`。以已验收的 lr1.5e-6 三种子为正式基线：
Top-1 均值 `0.705468833`、macro 均值 `0.705364744`、冲突子集均值 `0.308813790`。

新候选只有同时满足以下条件才可全量：

1. 三个 seed 的 Top-1 都高于各自的 lr1.5e-6 基线；
2. Top-1 均值至少 `0.705968833`（平均提升至少 `0.0005`）；
3. macro 均值不低于 `0.705364744`；
4. 冲突子集均值不低于 `0.308801864`；
5. 三项训练完整、历史 epoch 连续；
6. 无 NaN / Inf；
7. `best.pt`、`last.pt` 可加载；
8. 配置、输入与 commit 哈希一致；
9. 没有 test 访问。

任何一项失败即停止，不启用 full config。

## 5. 第二批条件实验（非必跑，按第一批结果触发）

- **8.1** 若 lr1.60 或 lr1.65 CE 通过：直接选合格项中 Top-1 最高者进入多种子，**不再扩大 CE 学习率搜索**。
- **8.2** 若 lr1.75 cwh 有效但总体下降较多：只再测一个更保守的软权重版本，**仅改 `min_weight: 0.2 → 0.5`**。
- **8.3** 若 6 epochs 时曲线仍在稳定上升（第 5、6 epoch 连续提高且冲突指标未持续下降）：才允许预注册 8 epochs 对照。
- **8.4 暂不重复**：`label_smoothing=0.05`、visual prototype weighting、原始 lr1.75 CE 全量、
  更高统一学习率、LoRA rank/alpha 扩张、任何多模型方法（违反单模型约束）。

## 6. 资源与执行

- 单卡单进程串行（本机仅 1 张 RTX 4060 Laptop，8 GiB）。
- 每项实测约 31 分钟、峰值显存约 1.15 GiB、磁盘约 0.45 GiB；三项合计约 95 分钟、约 1.4 GiB。
- 每 10 分钟只读心跳（进程 / GPU / checkpoint 时间 / 磁盘）。
- 异常时保留现场；仅当同一 commit、同一配置、同一输出目录存在有效 `last.pt` 时才允许 `--resume`。

## 7. 强制停止线

1. test 被训练或调参流程访问；
2. 使用非 OpenAI 官方权重；
3. 出现模型集成或投票；
4. HEAD、配置或输入哈希不一致；
5. 指标出现 NaN / Inf；
6. checkpoint 无法加载；
7. 输出目录状态不明确；
8. seed1 未过门禁却启动 seed2/seed3；
9. 三种子未过门禁却启用 full config；
10. 根据结果事后改变门禁；
11. 同一 GPU 上并发两个正式训练。
