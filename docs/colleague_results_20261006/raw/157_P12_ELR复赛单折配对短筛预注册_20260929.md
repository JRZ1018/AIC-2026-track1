# P12：基础 ELR 对比 SCE 的复赛单折配对短筛

日期：2026-09-29（Asia/Shanghai）。本任务仅在本机 RTX 4060 执行，服务器已关停且禁止连接。目标是筛选一个新的单模型训练损失；不保证线上提分，也不授权全量训练、test 推理或线上提交。

## 背景与唯一假设

P11 同折 SCE 对比 NCE+RCE 在折2仅增加四视图 Top-1 `+0.08743pp`，近重复组 bootstrap 区间跨 0，按预注册失败止损。下一项选用不同机制的基础 ELR：历史预测目标与当前输出的一致性正则，假设它能减缓模型对观测噪声标签的后期记忆。ELR 的机制来自已登记的 NeurIPS 2020 论文；本项目现有实现为独立最小实现，没有复制上游代码。该论文在其他数据/训练起点上的结果不构成本赛事的收益证据。

ELR 曾因 P3 的 GCE、LogitClip 均未增益而没有执行冻结特征对照（见 docs/04、docs/05）；P12 是一个不同的 Stage2 PEFT/H1 初始化场景下的有界再检验，保留先前的排除证据，不把它改写成已采用方法。只检验基础 ELR，不用 ELR+、多模型、外部数据或额外预训练权重。

## 配对设计

- 对照为 SCE `(alpha=0.1,beta=1,A=-4)`；候选为基础 ELR `(beta=0.7,lambda=3.0,eps=1e-6)`。候选固定使用现有 ELR 默认超参数，不做系数/种子/轮数网格。
- 两组均从同一 Stage2 折2 H1 `20260925-stage2-fold2-c5-h1-336-seed20260921/best.pt` 初始化；同一官方 OpenAI CLIP ViT-B/32、fold2 固定 118,958/29,737 train-derived split、336输入、末8视觉块 LoRA、AC、seed 20260921、batch64、同一优化器/LR/裁剪/增强，训练8轮。唯一算法变量是基础损失。
- ELR 每样本项为 `CE_i + lambda*log(1-<p_i,t_i>)`，再使用与对照相同的归一化 AC 权重作加权均值。AC 的历史更新仍由 detached CE 定义；训练样本索引只来自 fold2 train。ELR 历史目标使用 CPU float32，状态上限512 MiB；last checkpoint 必须保存并恢复该状态。
- 对照也使用同一新增训练器源码，以保证实现环境一致；SCE 分支语义不变。任何状态键缺失、损坏、超内存门限、AC 进入 L2 或来源哈希改变均停止晋级。
- 候选 checkpoint 按 fold2 train-derived validation 中心视图 Top-1 选 best；只在训练完成后，对 best 各执行一次固定384四视图 train-only 诊断。近重复组 bootstrap 固定500次、seed 20260925；同时报告 macro、tail类均召回、排除跨标签精确重复的 ordinary group。

## 事前筛选门槛

ELR 只有同时满足以下条件才值得申请另一折确认：

1. 固定384四视图 Top-1 相对匹配 SCE `>= +0.30pp`；
2. 近重复组 paired-bootstrap 95% CI 下界严格大于0；
3. macro accuracy 增益 `>=0pp`，tail类均召回增益 `>=-0.25pp`，ordinary group 增益 `>=0pp`；
4. 两组均完成8/8轮、全29,737验证样本、逐项来源SHA匹配、best 与 metrics/诊断SHA一致、last 可用 CPU `weights_only=True` 加载且包含模型/optimizer/scheduler/scaler/RNG/AC；AC每轮均非L2。

任何主门槛失败即停止这组 ELR 参数，不扫 beta/lambda/eps，不扩种子或全量、不读取 test。单折通过也只解锁另一折确认评估，不自动成为最终方案。

## 资源与恢复

- 仅本机 RTX 4060；预计配对高占用3–4小时，硬上限6小时，诊断和bootstrap包含在同一总时限。训练前至少5 GiB可用显存、12 GiB D盘空间；预期新增3–5 GiB，任何时刻不得覆盖既有产物。
- 队列使用仓库原子训练锁及全系统 trainer 探测，两个独立 run 目录串行运行；训练器每轮原子更新 last。硬截止时仅终止本队列启动的准确子进程树，保留最近完整 last，不自动续训。
- 初始、best/last及报告哈希、命令、环境、GPU/RAM/磁盘和资源收据写在队列目录；checkpoint 只在 CPU 用 `weights_only=True` 验收。训练锁含混、子进程终止未确认或产物损坏时不清锁、不重跑。
- 数据边界为 Stage2 官方 train 及其既有固定划分；不读取、索引或解码 test。无服务器依赖，无额外数据/权重，无提交。
