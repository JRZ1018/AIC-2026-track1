# P21：SCE+AC 折2 20 轮日程短筛（2026-10-01）

## 目的与边界

P17 EMA 相对同轨迹 raw 的四视图 Top-1 为 −0.053805pp，按原门槛止损。P13 的同配方 8→14 轮在折2、折3 train 派生验证各有正收益。因此只考察**训练总轮数 20**，不改官方 OpenAI CLIP ViT-B/32、Stage2 train、折2划分、H1、SCE(0.1,1,−4)、AC、末8块、batch64、seed20260921、学习率和冻结的384四视图推理算法。

4090上训练的既有14轮折2是历史参照；新运行的16个 DataLoader workers与本机已验证的RGB冗余转换消除属于工程加速，源码哈希会单独冻结。由于历史14轮来源版本/loader设置不同，本批20轮结果**仅是探索性日程证据**，不能单凭此宣布严格单变量配对通过，更不直接解锁全量/test。若20轮不优于14轮，止损；若明显优于14轮，须用匹配源码/机器的确认实验或明确披露差异后再决定全量。

## 冻结执行与资源

- 单一新run：`20261001-stage2-p21-fold2-sce-ac-20ep-4090-screen`，配置 `configs/experiment/stage2_p21_fold2_sce_ac_20ep_4090_screen.yaml`。
- AutoDL RTX4090；只在同事所有trainer进程与原项目共享训练锁自然释放后启动。独立无test工作目录，官方Stage2 train图片硬链接，输入/源码逐文件SHA冻结。
- 预计约2–3小时4090高占用，硬上限3.5小时；新增磁盘峰值≤3GiB，启动前空闲≥9GiB、运行中≥5GiB。原子best/last，超时或空间不足仅停止本队列拥有的进程组，保留最后完整断点。训练未完成20轮不得分析为完成候选。
- `workers=16,prefetch_factor=4,persistent_workers=true`；有效batch与采样随机性不变。前15分钟记录GPU利用率、显存、CPU、内存和完整轮次耗时；若吞吐异常，仅在完整last后安全停本批，不中途改活跃算法。
- 只允许Stage2 train派生29,737条验证；不读test、不按线上榜分调参、不自行出包或提交。
