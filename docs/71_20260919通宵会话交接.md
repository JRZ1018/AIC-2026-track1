## 2. 本次会话最重要的两个测量学结论

### 2.1 线上噪声标尺 = **±0.164**

item R 是**同配置只换种子**（`mix` 0.75，12ep，种子 20260910 → 20260912）：得 60.8363，
而种子 20260910 得 61.0005。**差值 0.164 就是运行间/种子波动。**

**含义**：`0.5→0.75` 的 +0.2083 仅比噪声大 1.27 倍，**不可作为可靠排序依据**；
而 `0.10→0.05` 的 +0.3685 是 2.2 倍噪声，**可信**。今后凡效应小于 ~0.2 的单次观测，
必须重复测量或用中位数，不能直接下结论。

### 2.2 固定验证有"分辨率下限"

item O（`mix` 0.75）与 item L（`mix` 0.50）在固定验证上 `best_top1` **完全相同到 9 位小数**
（均 `0.721419573`），**线上却差 0.2083**。

**含义**：固定验证**能排序大改动，但量不出 ~0.2 级的线上效应**。
**本地"平"不再作为不出包的理由**；这条路径上凡有独立正面理由的改动，应直接出全量包用线上判定。

### 2.3 训练损失能分辨机制，但不能分辨种子

| 对比 | 训练损失差 |
|---|---|
| 换种子（O→R、W→AD、S→AB） | **+0.0004 ~ +0.0006** |
| 换机制（`mix` 0.5→0.75→1.0） | −0.0083 / −0.0315 |
| 换下限（mw 0.10→0.05） | −0.0388 |
| 换下限（mw 0.05→0.02） | −0.0272 |

**训练损失是机制效应的可靠探针，但对种子不敏感**——这是筛选阶段真正可用的信号。
