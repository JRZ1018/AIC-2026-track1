# 复赛 Day 2：AC 参数再校准验收

更新时间：2026-09-23（Asia/Shanghai）

状态：A1/A2 已完成；两项均停止，不进入多种子或全量训练。

## 1. 实验目的与固定条件

本轮回答一个单变量问题：Stage2 上初赛沿用的 AC 参数是否需要向更保守方向移动。

共同条件：

- Stage2 官方 train，固定 `118,958 / 29,737` split；test 未读取；
- OpenAI CLIP ViT-B/32、自然 H1、冻结头、解冻最后 4 个视觉块；
- batch 64、workers 16、prefetch 4、persistent workers；
- visual lr `1.75e-6`、wd `0.01`、clip `1.0`、seed `20260921`；
- AC warmup 1、momentum 0.8、history mix 0.5；
- 每轮只修改一个 AC 参数，8 epochs，按固定验证 Top-1 选择 checkpoint。

资源调度：先完成 2-epoch 双任务并发门禁。两个任务均正常完成，但双任务总墙钟约 550 秒，
同配置单任务约 297 秒，总吞吐仅约为单任务 0.54 倍。因此正式 A1/A2 使用共享训练锁串行
执行；A1 约 17.8 分钟，A2 约 17.7 分钟。

## 3. 门禁决定

两项方案均满足“有效质量未塌陷”的安全条件，但均未满足提分条件：overall Top-1、macro、tail
同时退化。零召回类少 1 个属于辅助改善，不能抵消总体退化。

因此：

1. A1 停止，不做多种子；
2. A2 停止，不做多种子；
3. `min_weight=0.02、magnitude_mix=0.75` 继续作为 AC 主线锚点；
4. 不把 A1/A2 checkpoint 送入全量训练或提交；
5. 不再在这两个参数附近做连续网格搜索。
