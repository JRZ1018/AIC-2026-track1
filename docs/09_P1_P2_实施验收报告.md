# P1/P2 数据契约与可控噪声基准验收报告

验收日期：2026-09-09（Asia/Shanghai）

## 1. 结论

P1/P2 已完成，可以进入 P3 计算经济型 CLIP 基线。本阶段只使用 NumPy/Pillow 程序生成图片和合成 logits，不使用官方数据、外部真实数据或测试集，也不运行任何上游仓库代码。

本阶段无法证明真实比赛精度提升。ELR 和 LogitClip 只完成数值与工程验证，正式效果比较必须在 P3 统一协议下进行。

数据契约与合成审计的 Git 证据为 `b1d5e6d`；ELR、LogitClip、测试与本文档随本阶段第二笔提交固化。

## 2. P1 交付

- `pyproject.toml`：项目包和 pytest 配置。
- `src/aictrack1/data/contracts.py`：显式阶段、路径、标签来源、类别映射、审计和划分契约。
- `src/aictrack1/data/class_mapping.py`：官方字符串 ID 与内部连续索引的无损双向映射。
- `src/aictrack1/data/manifest.py`：稳定样本 ID、文件 SHA-256、图像状态和 dHash；使用线程池执行只读检查。
- `src/aictrack1/data/duplicates.py`：精确重复与基于 4-band LSH 的近重复候选，不做全量两两比较。
- `src/aictrack1/data/audit.py`：类别频次、坏图、重复、同内容异标签和摘要报告。
- `src/aictrack1/data/splits.py`：重复簇不可拆分、类别感知、尾类最低训练保留的确定性划分。
- `scripts/build_manifest.py`、`scripts/audit_dataset.py`、`scripts/build_split.py`：可复现 CLI。

安全行为：

- 审计输出禁止位于数据根目录或任何源目录内。
- 测试源必须无标签；类别 ID 保持前导零。
- `missing/decode_error/truncated` 不会静默丢弃。
- 默认只有 `ok` 样本进入 train/validation；其余显式写为 `excluded_bad_file`。
- 开启 `allow_truncated_images` 时才能让已记录的截断样本进入后续划分，正式加载器仍须在 P3 实现对应容错。

## 3. P2 交付

- `src/aictrack1/data/synthetic.py`：程序化细粒度图像、长尾和真值生成。
- 噪声类型：symmetric、pairflip、family-confusion、instance-dependent、class-dependent。
- 异常类型：精确重复、轻微近重复、损坏图片和截断图片。
- `src/aictrack1/evaluation/noise_detection.py`：precision、recall、F1、AUROC、干净样本保留、噪声泄漏及 head/mid/tail 诊断。
- `src/aictrack1/methods/logit_clip.py`：依据 ICML 2023 论文独立实现；未复制无许可证仓库源码。
- `src/aictrack1/methods/elr.py`：基础单模型 ELR、CPU/GPU 状态、checkpoint 状态和显式内存门禁；未实现 ELR+。

- CoOp：核对 `PromptLearner`、`CustomCLIP` 与 Trainer 分离，P1 保持模型/数据接口解耦，但未复制框架代码。

- ELR：P2 最小单模型实现完成，P3 正式对照待执行。
