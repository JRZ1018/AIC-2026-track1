## 2. 核心科学结论

对照 `docs/53` 记录的 lr1.75e-6 CE 三种子失败：

| 配置 | seed1 Top-1 | seed1 冲突子集 |
| --- | ---: | ---: |
| lr1.5e-6 CE（当前线上最佳） | 0.705517292 | 0.308813781 |
| lr1.6e-6 CE | 0.706147552（+0.000630） | 0.308813781（±0） |
| lr1.65e-6 CE | 0.706244528（+0.000727） | 0.308813781（±0） |
| lr1.75e-6 CE | 0.706632435（+0.001115） | **0.306163013（−0.002651）** |
| **lr1.75e-6 + classwise history** | **0.711286724（+0.005769）** | **0.310139179（+0.001325）** |

1. **冲突退化不是"高学习率必然代价"**：lr1.6e-6 与 lr1.65e-6 在提高 Top-1 的同时，
   冲突子集完全保持 `0.308813781`，说明 lr1.75e-6 的退化是可以通过正则化避免的。
2. **classwise history 软权重成功修复了冲突退化，并带来大幅 Top-1 提升**：
   C 候选同时取得 +0.005769 的 Top-1 与 +0.001325 的冲突子集，是本轮最强候选。
3. C 的最佳点在 **epoch 5**，epoch 6 的 Top-1 略降（0.711287 → 0.710947）但冲突继续上升
   （0.310139 → 0.313453）。按 `docs/54` 第 8.3 节，这**不构成**"第 5、6 epoch 连续提高"
   的 8-epoch 延长条件，因此**不申请延长**。
