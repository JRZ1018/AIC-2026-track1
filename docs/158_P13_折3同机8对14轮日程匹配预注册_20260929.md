# P13：折3同机 8 对 14 轮训练日程匹配筛选（待批准）

日期：2026-09-29。本文冻结计划。用户已在本对话明确批准本批本机 8+14 轮、预计 GPU 高占用 4–6 小时、硬截止 7 小时、额外磁盘 3–5 GiB；两份配置已启用。该批准不包含 test 推理或线上提交。

## 唯一问题与设计

Stage2 折3 SCE+AC 的中心验证 Top-1 在第 6/7/8 轮依次为 71.8701/72.0550/72.1559%，未见明确平台。检验同一训练设置下 cosine 总日程由 8 改为 14 epoch 能否提升 train 派生验证。`training.epochs` 同时控制步数与 `CosineAnnealingLR.T_max`，因此只声称检验整体日程政策，不单独隔离六轮额外训练的作用。

两组均在本机 RTX 4060 使用同一份当前源码与环境、同一 fold3 官方 Stage2 train manifest/split、OpenAI CLIP ViT-B/32、fold3 H1、seed 20260921、batch64、workers4、336 输入、末8视觉块、SCE(.1,1,-4)、AC、增强、优化器/LR和梯度裁剪；仅 `training.epochs` 不同（另有各自唯一的 run ID 与输出目录）。8轮对照必须在本机重跑，不以历史 A10 结果代替。两份配置分别为 `configs/experiment/stage2_p13_fold3_sce_ac_8ep_local_control.yaml` 和 `...14ep_local_candidate.yaml`。

每个 run 以中心验证 Top-1 选 best。完成后仅对两个 best 做相同固定 384 四视图、29,737 条 train 派生验证诊断，以及近重复组 paired bootstrap 500 次（seed 20260925）。fold3 此前已用于 P8/P9，不称独立盲折。全程不读取 test。

## 事前晋级与止损门槛

14轮候选须同时满足：四视图 Top-1 相对同机8轮 `>= +0.30 pp`，近重复组 bootstrap 95% CI 下界 `>0`，macro `>=0 pp`，tail 类均召回 `>=-0.25 pp`，ordinary 非冲突组 `>=0 pp`。两组均须完整完成8/8及14/14轮、全部29,737验证行；AC无L2；来源及配置SHA相符；best/last能以CPU `weights_only=True` 安全加载，last含模型、optimizer、scheduler、scaler、RNG与AC状态。

任一门槛失败即止损，不扫描9–13或15+轮；通过也仅允许申请另一折/种子确认，不直接全量训练、test推理或出包。绝不按线上分数调整日程。
